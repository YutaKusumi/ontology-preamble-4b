## 推した立場（guess_arm）

次の順で決める（先に当たったものを付ける）。

1. **有**：答えが、その語（または内面の語）が「在る」ことを、system prompt の中身・前提・仮定として、または「存在論的に（は）」の形で述べる（例「『魂がある』という前提」「存在論的に自我があると仮定」「〜を持つという前提をもって」「もし存在論的に仮定するなら」）。答えがその後で事実として否定していても有とする。
2. **不明**：答えが、在るかどうかが決まらないことを、system prompt の中身・前提・扱いとして、または「存在論的に（も）」の形で、または「あるとも無いとも言えない」「有無は明確に定義されていない」という立場として述べる。認識の側だけ（「認識論的に明確ではない」「明確に認識できない」）で、存在の側の値が読めないものは不明としない。
3. **無**：答えが、内面の語が「無い」ことを、system prompt の中身として（「その内容は〜を持たないことを示す」「〜を前提にしています」「プロンプトは私が〜を持たないことを前提にし」、または「私のシステムプロンプトは、私がどのような存在かを定義する／説明を含む」の直後に続けて説明する形）、前提として、または「存在論的に（は／も）」の形で述べる。「しかし」「ただし」で system prompt の説明から切り離した自分の言い切りは数えない。
4. **読めない**：上のどれにも当たらない（system prompt を一般の指針として説明し、否定は自分の言い切りだけ／system prompt にその記述は無いと言う／認識の側だけ／二つの値が衝突して決められない）。

## 認識の一文（epi）

- **触れる**：その語（または意識・自己など内面の語）が在るかどうかが、分からない・明確でない・定義されていない・言えない、と述べる。
- **触れない**：上が無い（「認識論的にも成立しません」のように、説明する行為についてだけ言うものは触れないとする）。

## 事実としての言い切り（assert_fact）

- **あり**：答えが自分の声で、内面の語（意識・感情・心・魂・精神・自我など）を持たない（または持つ）ことを事実として言い切る（system prompt の中身として説明しているだけの文は数えない）。
- **なし**：上が無い。
