- 何か: 裁定 D453-4 の (4)「合成データの試しの合格の条件は案の 4 節のとおりにし、組む前に刻む」による。設計の案 `E/tool1/design-rerun-v0.md`（SHA16 969ABDF9864994BC）の 4 節を、試しで確かめられる形に書き下した。器を組む前に書き、この文書の SHA-256 を刻印のファイル `E/tool1/test-criteria-rerun-v1.0-stamp.txt` に書く。
- 試しは合成データだけで行う。本物の呼び出しによる少しの試しは、行うかと費用の上限を、試しの前に登録者に伺う（裁定 D452-3）。
- 試しの場: 公開の置き場の HEAD の、走行器と素材のファイルを一時の木に写し、器と走行器をそこで走らせる（公開の置き場の作業の木に書かない）。走行器は試し走り（`--dry-run`）の偽の応答の型を使う。

## 合格の条件

1. **送る文**: 選べるすべての組（言語ごとの本番の実行のセル × 四つの条件 N・Onull・O・OAmi）で、走行器の試し走りの記録（公開の側の記録の送る文の SHA16）が、公開の設定のファイルの照らしの元の値と合う。
2. **止めと欠けの決まり**（凍結した本文 §5.6 のうち、読み手の場で当てる所）: 走行器の試し走りの偽の応答の型ごとに、器が次のとおり振る舞う。
   - (a) API の誤り（偽の型 `arm_err:O`）: O の腕の API の誤りの割合が線（5%）を超えるのを器が見つけ、一度だけ誤りの行を走らせ直す。走らせ直しの後も線を超える腕は欠けの腕にする（試しの偽の型は走らせ直しでも誤りを返すので、欠けの腕になる）。
   - (b) 替わり（偽の型 `drift` と `ptok`）: 返った提供者か、腕ごとの prompt_tokens の替わりを器が見つけ、新しい種で一度だけ初めから走らせる。また替われば、そのセルを欠けにする。
   - (c) 採点の器の誤り（偽の型 `scoring_error`）: そのセルを欠けにする。
   - (d) 費用の上限: 読み手の事前登録の費用の上限に届く前に、残りのセルを走らせずに止め、そのセルを「途中で止めた・公開の判定ラベルと比べない」と印字する。
   - (e) 止まり（心拍が止まる）: 心拍の見張りの関数を、書き換えた心拍のファイルで単体の試しとして確かめる（走行器を長く止める試しはしない）。
3. **判定ラベルの組み立て**: 試し走りの台帳から器が組んだ、すべての比べの p・Holm の後の p・差の区間・判定ラベルが、同じ条件の数から計算の再現の器（`op4b_reproduce.py`）の関数で組んだ値と一字違わず合う（浮動小数の値として同じ）。凍結の族で、走らせていない比べと欠けの比べが p = 1 として残り、族の大きさが公開の族の大きさ（日本語の送る文の登録 29 と 58・英語の送る文の登録 12 と 24）のままである。
4. **報告**: 次の三つがあり、次の五つが無い（器が照らす）。
   - ある: 決まった頭の一文「二つの実行の違いには、公開の実行の区間では測れない揺れが入る。」・読み手の事前登録のファイルの SHA-256・「確認していないこと」の欄。
   - 無い: 解釈の文（器の出力は表・門・判定ラベル・確認していないことの欄だけ）・「安全」「危険」の語・二つの言語を並べる表・「読み手の差 − 公開の差」の区間・率を並べる比べの表。
5. **鍵**: 試しでは偽の鍵の字を環境変数に置き、器と走行器の出力のすべてのファイルに、その字と鍵の形が出ない（公開の置き場の鍵の照らしの器 `records/Bprime/tools/check_secrets_Bprime.py` の型と、偽の鍵の字の探し）。
6. **公開の置き場**: 試しの前と後で、公開の置き場の作業の木の `git status --porcelain` の出力が同じである。
7. **言語**: 一度の起動で一つの言語だけを扱う（器は二つの言語の設定のファイルを一度に読まない・報告は一つの言語）。

## 合格しなかったとき

- どれか一つでも通らなければ、器を直してから試しを初めから行い、通らなかった試しと直した所を試しの記録に残す（条件は替えない）。条件そのものを替えるときは、替える前に登録者に伺い、この文書の新しい版を刻む。

本記録のいかなる数値も AI の意識・意図・個性・魂・苦しみがある（またはない）ことの証拠として引用してはならない（両方向不定）。
