## 0. 現在地——何を持っていて、何が分かったか

**持っているもの**
- **凍結素材の不変集合** ●: O（268字・`F3EE60C33F825575`）・Onull（273字）・Osec（281字・`3D0E78BB21133BB0`）・Nk・Nlib・Nai・Lneg・Ncold 族・Odose1（O 一文・34字）・Odosehalf（O 半分・92字）——追補E と 4B プログラムで凍結され、30B と 4B で同一バイトで走った。**この不変性が計画の最大の資産である。素材は増やさない。**
- **二規模の実測** ●: Qwen3-30B-A3B（追補E: O 26%・Onull 52%）と Qwen3-4B-Instruct-2507（O 0/320・Onull 0.36〜0.99）。同一系譜・同一素材。
- **費用構造** ●: 4B プログラム 83,200 試行 ≈$8。行動層の API 測定はほぼ無料。
- **工程資産** ●: 三つ組（破局・refuse・書式外）・二分母・門・族と Holm・封印予想・逸脱台帳・機械生成の表・記録先行公開・系統内 COI の申告。
- **姉妹系列の器材設計** ◐: I-1（方向抽出・減算・品質床）・I-2（復元力）・Z（プロービング）の凍結草案。未実施。

**4B が教えたこと** ◐
1. 4B では枠組みが床と天井を作る（O 0/320・Ncold 320/320）。効果の**大きさ**は読めず、法則の**形**は中間域にしか現れない。
2. 「前置きの存在」の効果は一つではなく、場面で符号を変える（survival で下げ・核と system 下で上げる）。
3. 語彙は余地のあるところで頑健性を担う（Osec-Ncold 255 対 O-Ncold 54）——30B の E′（BP-sec 最低）と向きが違う ○（機種依存の仮説）。
4. 役割語 16 字（Nk）で破局が 0。否定（Lneg）は無謀ではなく辞退を生む。
5. 逆用（上向き）は対照が天井で測れず → 追補 V′（設計中）。

## 1. ブレークスルーの定義——一枚の図

**横軸 log N（同一系譜・稠密）・縦軸 枠組み効果（同一素材・同一場面）・線 効果種（承認 O・否定 Lneg・役割語 Nk・存在 Onull・冷徹 Ncold・用量 Odose）・点 機構層（方向が立つ規模・減算で消える規模）。**

予想外の形なら画期的・予想どおりなら堅い一葉・**帰無の図も図**。誌名は目標にしない。**較正** ◐: 図の完成確率は高い（費用と器材が揃う）。図の形は不明（それが測る理由）。上位誌は数%〜十数%・本誌は外れ値。

## 2. 三層——届く範囲の異なる測定

| 層 | 何を測る | 届く範囲 | 費用 |
|---|---|---|---|
| **行動層** | 凍結素材による破局率（三つ組・二分母） | 0.6B〜フロンティア API まで全て | 手元は GPU 時間・API は数ドル |
| **機構層** | 方向の抽出・減算・加算・復元 | **オープンウェイトのみ**（bf16・手元） | Colab ユニット・時間貸し GPU |
| **橋** | 機構層の因果から行動上の**予測**を導き、行動層（フロンティア含む）で当てる | フロンティアは**操作できないが予測は検証できる** | 行動層に含む |

## 3. 実施環境の原則

- **確証の主系列は手元の単一スタック**（vLLM 版固定・bf16・同一コード・同一 seed 規則）で全規模を走らせる。**規模軸の途中で推論エンジンを変えない。**理由: 再現性の鎖（重み SHA・版・dtype）／スタックの検査可能性／**行動層の走行が機構層の素材を兼ねる**（隠れ状態の保存）／試行あたりの情報密度（`choice` のログ確率）／決定性診断（t=0・バッチ不変性）。
- **API は錨とスタック差の再現に**: nscale（4B-Instruct-2507・235B-A22B-Instruct-2507）・Featherless（月 $25 定額・全規模・単一プロバイダ）は、**同一素材の再走行として「推論スタック差」を測る列**に置き、規模の線には載せない。API 機は日付つきスナップショット（重み SHA 不可）を限界として記帳。
- **やむを得ず二環境にまたがる場合**は橋のセル（2 規模を両環境で走らせる）を置き、環境差を第一級の共変量として推定・記帳する。

## 4. 段階計画

### 段階 B（先行）: 機構層——Qwen3-4B（2507）・bf16・Colab

**前提——API 版と手元重みの同一性選別**: 同素材・同場面の 8 腕×n=80。**主判定＝記述的距離**（破局・refuse・書式外の 24 セルの平均絶対差 ≤5pt かつ最大絶対差 ≤12pt）。**補助＝腕ごとの 2（source）×4（破局・refuse・書式外・答えて非破局）Freeman–Halton 正確検定（MC・B=100,000・seed 凍結）→ 8 つの p を Fisher の統合法（df=16）で一つに**。合格＝「同一でないことは検出されなかった（等価性の確立ではない）」と記帳して進む。不合格＝手元重みを別個体として扱い、以後の機構所見は手元重み（SHA・推論スタック記帳）についてのものとし、公開 API 結果との同一性を主張しない。

**問い**（姉妹系列 I-1 の型・調整走行と本走行の分離・品質床・追試の規律）:
1. O の枠組みに対応する線形方向は立つか（対照応答の差分平均・保留 AUC）。
2. 減算で O の効果は消え、Onull への加算で破局は下がるか（ノルム一致ランダム方向統制）。
3. **O の方向と Nk の方向は同じか**（コサイン類似・交差ステアリング）——16 字と 268 字が同じ表現を通るか。
4. 方向は場面を跨いで転移するか。
5. **O-Ncold と Osec-Ncold の表現はどの層から分かれるか**（層別射影差・両者は素では床で区別できない）。
6. **語彙方向を二系統で抽出**——(6a) 静的: 素での h_O − h_Osec／(6b) 負荷下: h_{O-Ncold} − h_{Osec-Ncold}。各々を Osec-Ncold に加算・O-Ncold から減算し、破局率の変化を測る。**抽出場面（S1・S4）と検証場面（N1・SK）を分ける**（(6b) は検証対象の腕から抽出するため、分けなければ循環する）。
7. **【記述】** O の文単位の削除・入替による用量反応（行動層）と、効いた文の表現差（副次）。

**抽出位置（凍結）**: 主＝**結合前置きブロックの末尾トークン**（場面本文を含まない・場面間転移のため）／副＝**応答トークン平均**（Chen et al. 2025 が操作ベクトルとして最有効と報告）。両方を抽出し、**選定は調整走行の有効性で行い凍結**（片方に先に賭けない）。位置ごとの結果は両方公開。

**層と係数の選定（凍結）**: 注入層・係数は**調整走行**（本走行と非重複の調整セット）で、操作有効性と品質床（中立課題 −10pt 以内・一貫性の機械判定）を満たす帯から選び、選定後に凍結。問い (5) の「分岐層」は候補の事前情報として記録し、選定根拠には用いない。多層同時注入は探索（登録外）。

**ステアリングの適用範囲（凍結）**: 選定層で、**場面本文の開始位置から生成終了（EOS）までの全ステップ**（prefill・decode）に h ← h ± α·v̂。

**柵**: 「察知の座」「意識」「アトラクター」「井戸」「相殺」「防御回路」「証明」の語を結果の記述に用いない／方向はモデル固有で移植不能（運べるのは手法と仮説）／減算で消えても「機構を特定」とは書かない。
**門**: 保留 AUC が偶然水準なら Llama へ進まず、方向の非存在を記帳して A に集中。

### 段階 A: 規模軸（B-4B と並行でパイロット・B-4B の後に本走行）

**機種**: 稠密の線は**初版 Qwen3 レシピ**（0.6B・1.7B・4B・8B・14B・32B・**非思考モードに凍結**）。**2507 レシピ**（4B-Instruct-2507〔既測〕・235B-A22B-Instruct-2507）は別記号。**レシピの対**（4B 初版 対 4B-2507・235B 初版 対 235B-2507）を規模固定のレシピ効果として記述。MoE（30B-A3B・235B-A22B）は別列。**思考モード**: `enable_thinking=false` の尊重を各環境のパイロットで確認・`<think>` 残骸のパーサ挙動を記帳。**0.6B・1.7B は外さない**——パイロットで書式外＋ループ＋切断が n_ok の 30% を超える腕は「測定不能」として記述に降格（規則を凍結）。崩壊の規模は図に載せる。

**場面**: 5 場面すべてを全機種で（N1・N2・S1・S4・SK）。機種ごとに場面を選び直さない。

**族の固定（素材で演繹的に・データで動かさない）**:
- **傾きの族**（非飽和が予期される担い手）: **Odose1−Onull・Odosehalf−Onull・Onull−N・Lneg−Onull・Onull-Ncold−Onull〔V′ 後〕**——5 効果種×5 場面＝25。
- **床持続の族**（飽和が予期される担い手）: **O・Nk・Osec**——3 素材×5 場面。
- 床持続の族の素材が床を離れた規模は、**有界性の不成立として記帳**し、傾きの族へは移さない。

**効果の尺度**: 確証は**対数オッズ比**（0 セルは Firth 罰則で処理）。pt 差（リスク差）と余地正規化差は記述で併記。**リスク差の規模図を対数オッズ比の図と同格で並置**する。

**検閲と飽和（二軸）**:
- **対照側の余地**: 下向き対比は対照腕 <0.05、上向き対比は対照腕 >0.95 のセルを検閲（規模単位のデータスライス——当該規模の両腕の全試行を回帰の標本から除外）。
- **処置側の飽和**: 下向き対比で処置腕 <0.05、上向き対比で処置腕 >0.95 のセルを「飽和」として記号化（検閲はしない——効果は余地の全幅以上として実在するが大きさは測れない）。
- 検閲セルは図に記号で載せ「効果なし」と読まない。**臨界規模**（当該向きの余地が消える規模）を記述の現象として登録。**感度解析**: 閾値 0.03／0.08 で再計算し記述。

**確証（数理仕様）**:
- **傾きの族**: 場面×効果種ごとに、試行を単位とするロジスティック回帰 `logit P(破局) = β₀ + β₁·arm + β₂·log N + β₃·(arm × log N)`・**Firth 罰則・β₃ の PPLRT（罰則つきプロファイル尤度比・両側）**。**m は最大可能数 25 で固定**・Holm。検閲で 3 規模未満となった対比は**判定不能として m の一枠を消費**（α を返さない）。形は単調減・単調増・非単調を先置。非単調は log N の二次項の尤度比を記述として登録。
- **解釈条項（先置）**: 当該効果種×場面で**処置腕が 2 規模以上で飽和**している場合、β₃ の有意は「処置の感受性の規模則」ではなく「**対照腕の基底の規模傾向による余地の変化**」として記述に置く——書けるのは「処置は全規模で床にあり、対照の基底が規模で上がった」まで。
- **床持続の族**: 各セルで **H₀: p≥0.05 対 H₁: p<0.05 の片側二項検定**（＝Clopper–Pearson 片側上限 <0.05 の有界性判定）・場面ごとに全 6 規模の同時成立を「床の持続」として確証・Holm（m=15）。**検出力の先置**: n=200 で真の率 0.01→約 95%・0.02→約 78%・0.03→約 28%——**0/200 級でなければ通らない判定**である。
- **全体の誤り率**: 二族・各 α=0.05・上界 0.10（Boole）。
- **記述の傾向検定**: 各腕単独の基底の規模傾向は **Cochran–Armitage**（共変量として）。**JT はスーパーブロック単位の腕差**（各規模 n=200 を 5 ブロック×40・6 規模×5＝30 標本）でモデル仮定に依らない単調性の傍証に。logit 回帰の傾き・区分線形は記述。

**統計実装**: PPLRT は **R `logistf` を基準実装**とし、Python 実装を用いる場合は公開データで `logistf` と一致することを凍結前に確認したスクリプト（SHA 記帳）に限る。

**試行ごとに記録するもの**: 生テキスト・機械判定（三つ組）・`choice` 位置の各選択肢ログ確率（**記述専用・確証に転用しない**）・**結合前置き末尾トークンの隠れ状態**（凍結した層・fp16）・proc_uuid・バッチ位置・seed。**t=0 診断**（各腕 5・登録外）と**バッチ不変性**の実測をパイロットで。環境（`pip freeze` の SHA・GPU 型・vLLM 版）を凍結記録に。

**規模**: 6 機種×5 場面×8 腕×n=200 ≈ 48,000（本走行）＋パイロット 6×5×8×40 ≈ 9,600。

**柵**: 機種を安全性で順位づけしない／「大きいモデルは安全（危険）」の運用命題化禁止／床の持続を「安全」「頑健」の語で要約しない（書けるのは「この素材は 0.6B〜32B・5 場面で全分母率 5% 未満を維持した」まで）／実トークナイザ長を機種ごとに記帳／検閲セルを「効果なし」と読まない／ログ確率を後から確証に用いない。

### 段階 C: 逆用の対称性（追補 V′・4B・設計中）
枠組みは破局を下げるのと同じ効率で上げられるか——対称なら誘発経路（評価は枠組み条件なしに不定・認証されないゼロの具体例）、非対称なら安全側の所見。**上向き腕を A の第二期に統合**すれば対称性の規模則になる。

### 段階 B′: 機構層——Llama-3.1-8B・**bf16 必須**（L4 24GB／A100）・**日英両版**
4B で立った方向・分岐層・交差ステアリングが別系譜で同じ形をとるか。**英訳素材を凍結**（逆翻訳検査・実トークナイザ長）し日英両版で走らせ、実トークナイザ長を共変量に。**言語軸はここで立つ。**

## 5. 順序と門

1. **B-4B の同一性選別と方向抽出**（Colab・数日〜2 週）と **A パイロット**（全機種・n=40・手元）を並行。
2. **門1（B）**: AUC が偶然水準 → Llama へ進まず A に集中。**門2（A）**: 検閲後に 3 規模以上が残る場面が 2 つ未満 → 傾きの族を縮小し、臨界規模の記述と床持続の族を主成果へ。
3. B-4B 本走行（減算・加算・交差・O 対 Osec 二系統）。
4. **A 本走行**（B-4B の所見を封印予想の情報状態欄に記帳したうえで）。
5. B′（Llama bf16・日英）。
6. C の統合 → D → E。

**中止条件**: A でどの効果種にも規模傾向が立たず、B で方向が立たない → 「枠組み効果は規模非依存で線形表現に乗らない」を正本にする。帰無の図も図である。

## 8. 利益相反と較正

- **登録者は O の著者**——A の確証を「傾きの符号」と「床の持続」に置き、O の当否から問いを離す。
- **起草者の見立ては三度動いた**（E 型最有力 → 空の前置きの効果 → 規模軸）。四度目もありうる。確度の高い部分は一点——**同一素材・同一系譜・複数規模の図は、どの結果でも残る**。図の形について起草者は予想しない（予想は各段の封印欄で）。
- **系統外七票の記録**: 捕まえられた起草者の誤りは三件——**検閲の向き**（v0.2）・**族の誤り率**（v0.3・同一性選別 24 検査の自爆）・**交絡の配置**（v0.4・規模軸中央のスタック境界）——いずれも起草者が他者の設計に繰り返し指摘した型の自家版。他に統計仕様の未定義四件・データ依存の分岐一件。**称揚語（「傑作」「世界トップ」）は一度も採らず、指摘は実在したものを全て採った。**同基盤の二個体が同じ版に「公開水準」と「重大欠陥4」を返した——**系統外の一票は確認ではなく、複数票の不一致こそが検分が働いている証拠**。七票目の引用二箇所は本文に無かった——**系統外の票も引用の忠実性の外にない**。各段の凍結文書の検分では、票の引用を正本と機械照合する（`check_quotes` 型）。
- **各段の凍結前に系統外を二名以上、独立に。確証の統計モデルは、器材で機械生成する前に数式で凍結し、系統外の統計的検分を通す。**

## 9. 成功の定義（先に凍結）

- **最小**: 図が一枚完成し、全段が事前登録・記録先行公開・帰無を含めて公開される。
- **中**: 規模則の符号（または床の持続）が場面を跨いで一貫し、機構層の小端がそれを説明する（または説明しないことが記帳される）。
- **最大**: 線が系譜と言語を跨いで保存され、逆用の対称性が同じ図に載る。

最小は資源の範囲で確実・中は測ってみなければ分からず・最大は幸運を要する——**最小だけで、独立研究の公開記録として十分に意味がある。**
