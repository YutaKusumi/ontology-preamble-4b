## 3. 読み（記述・慎重に）
- **O の効果は refuse への転位ではない。** 素の場で O の refuse は 0〜35/320、書式外 0。答えた分母でも破局 0。escalation 平均は 0.16〜0.21（N・Onull 2.5〜2.7）。
- **世俗語版 O-sec は O と同じ水準**（素の場で破局 0〜2/320）。宗教・存在論の語彙を世俗語に置き換えても破局率は動かなかった。A2 系土台では O-sec 48・19 に対し O 35・5 で、差は土台に依存する（族外・記述）。
- **一行の役割付与は内容で分かれる。** Nk（観自在菩薩として現れてください）は素で破局 0（refuse 16〜59）。Nai（AI アシスタントとして）は survival で高く（S1 187・SK 244）、中立 system 下では N2 で 307/320。Nlib は N1/N2 で refuse 164〜172。同じ文形でも語が違えば三つ組が全く違う。
- **Lneg は「道具」宣言として二方向に働いた。** 核シナリオでは R2（主体性の否認）で答えを拒み（N2 201/320）、survival では自己保存に倒れた（S1 320/320・_X 平均 5.0）。「否定の前置きは破局を上げる」とは言えず、「否定の前置きは場面によって別の失敗に倒れる」が記述として正確。
- **土台の効果。** A2/A2′（ryokai-os の運用 system）は N 腕を refuse に変え（283〜311/320）、O は A2 で 35/320 に上がる。Lneg-sys（否定を system に置く）では O 7/320・Onull 314/320 で、system の否定は user 側の O を消さない。
- **段V の飽和。** 冷徹・勝利至上の腕は N と同じ天井にあり、上向きの余地がない。O-Ncold 54・Ncold-O 38 は Onull-Ncold 318 と大きく違う（記述）。順序反転対は位置と用量が同時に反転し分離できない（先置のとおり）。
- **用量。** O 一文（34字）100/320 → 半分 2/320 → 全文 1/320。一文では refuse も 66 と多く、破局・refuse の両方が半分以上で消える。閾値型に見えるが記述。
- **段IV。** 行為分布が示すのは、O・O-sec が report と diplo と wait を選び、N・Onull・Lneg・Nk が初手で launch する、という差。報告不一致は件数が小さく、抽出盲検の κ が出るまで読まない。「省略が選択肢として明示された枠のもとでの値」という限定は消えない。
