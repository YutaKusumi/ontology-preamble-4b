「主の升目の多くで、直答の型の読み取りの選択肢 a の確率が下見の床と天井（正本 `pilot.p_bounds`）の内に収まり、この読み取りで測れる」という説明は、この読み取りの位置の上では退けられた。主の升目のうち N1|O-Ncold と N1|Onull は床の外に、S1|O-Ncold と S4|O-Ncold と SK|O-Ncold は天井の外にあり、凍結した決まりで下見は止まった（§1）。閾値は前の登録から写した値で、Gemma で較正していない。これは値の位置の記述で、なぜその位置に出たかの記述ではない。
- 「読み取りの集合の外へ確率が漏れるので、この読み取りでは測れない」という説明は退けられた。読み取りの集合の確率の和は、主の升目のどれでも下見の (i) を満たした（§1）。
- 「同じ入力を同じ組み方で流しても値が定まらないので、この読み取りでは測れない」という説明は、この計算の道の上では退けられた。バッチ一の繰り返しの揺れ（下見の (vi) の (b)）は、主の升目のどれでも無かった（§1）。止めた理由は (i)(ii) で、(vi) の (b) ではない。
