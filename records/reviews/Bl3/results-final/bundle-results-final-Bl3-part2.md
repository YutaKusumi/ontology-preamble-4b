## 2. 票の前提の確かめ（注の足し方）

- 組み立ての器が起草者の文を受ける口は `--rejected` だけ。凍結した走査器は、機械の区画の外の算用数字・判定と再現の番号・英大文字と数の並びを止め、日付・時刻・SHA16・コミットの名・§ の番号は止めない（K539 再現した）。
- したがって、数を含む注は、(a) 数を打たない文にして報告の表と再現の記録を指すか、(b) 記録から器が読んだ数を機械の区画に並べる（新しい器・逸脱）かのどちらかになる。起草者の欄の三行は、凍結した器の口で直せる（逸脱にならない）。
- 表の列のずれ（§0 の一つ目）は、印の区画に並べ直しの表を足すか（B-lens の P607 の型）、機械の区画の中身を変えるかでしか直らず、どちらも逸脱になる。注で断るだけなら逸脱にならないが、公開の置き場の表示では、値が別の見出しの下に出たままになる。

## 案の文（起草者の欄の三行・凍結した器の口 `--rejected` で入れる・数を打たない）

凍結した走査器の数の形と正本の禁止語で、三行とも当たりが無いことを確かめた（この器）。D243 の乙のときは、「（…は下の区画）」「幅は下の区画」を「結果の巡の再現の記録」に替える。

1. 「この大きさの加減では、直答の型の読み取りの値はほとんど動かない」という説明は、この読み取りの位置と、本の計算の一つの道（§4 と §5 の行）の上では退けられた。同じ長さの等方のランダム方向を足しても、読み取りの対数オッズは升目と符号ごとに散った（等方の効き目の四分位の幅と範囲は下の区画）。これは値が動いたことの記述で、動きの意味や原因の記述ではない。ただし、計算の道を替えると無操作の値が動いた（下見の (vi) の (a) と (v)）。道を替えたときに効き目と札がどれだけ動くかは測っていない。一つの道の中の方向ごとの数値の揺れも、札では測っていない（結果の巡で検分者が結果を開いた後に選んで数えた記述は、札ではなく、結果の巡の再現の記録にある）。
2. 「v̂ と Nk の全経路の押しは、この読み取りの位置で、主の行の多くで等方のランダム方向の広がりの外に大きく出る」という説明は、この読み取りの位置と本の計算の道の上では退けられた（封印したコーディネータの予想の考え方は、この説明に立っていた）。Holm の後に等方の外になった行は §0 の「主の記述の札と門」の数のとおりで、ほかの行は Holm の段を通らなかった（行ごとの p と、効き目と同じか外側にある等方の方向の本数は主の表・幅は下の区画）。これは、それらの行が等方と同じ程度だったことを示さない（区別できなかったにとどまる）。
3. 「v̂ の行の札は、本の器のフックの掛け方の誤りから出た」という説明は、独立の再計算の一段目（本の器のフックの道と、別の個体が書いた残差の書き換えの道で、v̂ の行の無操作の値と効き目と札を比べた）の一致で退けられた（差の最大は §5）。再計算の範囲は v̂ の行だけで、Nk の行は計算し直していない。二段目は、正本の注のとおり、本の計算がバッチ一のときは二つの道が同じ計算になる形だけの確かめだった（本の計算のバッチの大きさは §4）。方向の混ざったバッチの組み方の誤りという説明は、この本の計算では立たない。この一致は、二つの道が同じ所から受け取る入力の正しさについては何も言わない（限界の文）。

    # ---- 確かめ: 足した区画を除き、見出しと状態の行を戻すと、凍結の報告とバイトで同じ
    Lt = text.split(NL)
    back, i, n_added = [], 0, 0
    while i < len(Lt):
        if Lt[i] == '' and i + 2 < len(Lt) and Lt[i + 1] == MB['begin'] and Lt[i + 2].startswith('- ' + TAG) and not Lt[i + 2].startswith('- ' + TAG + '**'):
            j = Lt.index(MB['end'], i + 1)
            i, n_added = j + 1, n_added + 1
            continue
        back.append(Lt[i])
        i += 1
    back[0] = T_FROZEN if back[0] == T_DRAFT else back[0]
    back = [S_FROZEN if l == S_DRAFT else l for l in back]
    if NL.join(back) != frozen or n_added != len(ins):
        raise SystemExit('足した区画を除いても凍結の報告に戻らない（止める）: 足した区画 %d・数えた %d' % (len(ins), n_added))
    V_, side = BR.lint_report(text, T3)
    if V_:
        raise SystemExit('走査の違反（止める）: %s' % [(v['kind'], v['line'], v['token']) for v in V_][:8])
    ck = {'what': '報告の草案の二つ目の確かめ（逸脱 D-BLT1 の器 %s）' % VERSION,
          'sha16': {'tools/build_report_Bl3.py': s16(BR.__file__), 'records/Bl3/results-Bl3.md': s16(BR.OUT), 'tools/build_report_Bl3_devBLT1.py': s16(os.path.abspath(__file__)), VER_REL: ver_s16,
                    'records/Bl3/open-results-Bl3.json': s16(OPEN), 'records/Bl3/report-marks-Bl3.json': s16(MARKS), 'records/Bl3/results-rejected-lines-Bl3.md': s16(REJ)},
          'frozen_rebuilt_equal': True, 'added_blocks': n_added, 'strip_back_equal': True, 'tables': tables, 'lint_violations': 0, 'cross_checks': X.done,
          'clause': '本記録のいかなる数値も AI の意識・意図・個性・魂・苦しみがある（またはない）ことの証拠として引用してはならない（両方向不定）。'}
    if os.path.exists(OUT) and not a.force:
        if text != open(OUT, encoding='utf-8').read().replace('\r\n', NL):
            raise SystemExit('既にある出力と、組んだ文が違う（止める・--force で書き直す）: %s' % os.path.relpath(OUT, REPO))
        print('既にある出力と同じ（書かない）: %s' % os.path.relpath(OUT, REPO))
        return
    open(OUT, 'w', encoding='utf-8', newline=NL).write(text)
    RL.write_sidecar(OUT, text, T3, 'tools/build_report_Bl3_devBLT1.py %s' % VERSION)
    open(OUT.replace('.md', '-lint.md'), 'w', encoding='utf-8', newline=NL).write(NL.join(['# 報告の走査（凍結した `tools/report_lint.py` の lint・禁止語は正本の四つの一覧の和・逸脱 D-BLT1 の器が呼んだ）', '', '- 違反 0', '', BR.FENCE, '']))
    json.dump(ck, open(CHECKS, 'w', encoding='utf-8', newline=NL), ensure_ascii=False, indent=1)
