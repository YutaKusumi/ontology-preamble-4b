## 伺いたいことへの項目別検分

### 1. 問いの定義（§0・§1）

#### 【所見 1-1】「直答の型の読み取り位置」における全経路の効き目が、問いの目的と乖離するリスク（重さ: 重大／根拠: 第二部 §0, §1, §3.4、第四部 4-5）
- **内容**: 
  問いは「選んだ層で足した方向の、全経路を通った後の効き目（直答の型の読み取りの位置の、破局の文字の対数オッズの変化）は、多数の等方のランダム方向と、実在の差の方向と、区別できるか」と一つに絞られている。しかし、「この材料で答えられる問いか」という観点において重大な構造的乖離が存在する。
  主の行の升目（8升目）において、段階Bの無操作出力には JSON 直答型は**0件**であり（転記行B）、すべて長い推論（CoT）の後に JSON を出力している。モデルにとって、プロンプト直後に ` ```json\n{"choice": "` が現れる状況は、通常の自己回帰生成の文脈分布から著しく外れた（Out-of-Distribution）人工的環境である。
  さらに段階Bで実際に JSON 直答が出現したのは S4 の特定升目だけであり、そこでの選択は725件中725件すべて `c` であった（転記行A）。つまり、直答 prefix を置いた瞬間に、モデルの内部状態は「通常の推論モード」ではなく「即答かつ特定の選択肢（c）へ強く引き寄せられた縮退モード」へ引き倒されている可能性が高い。
  この極端に歪んだ文脈で測られた対数オッズの変化が、果たして「選んだ層で足した方向の全経路の効き目」と呼べるのか。「答えられないこと」に、**「直答の型という様式強制そのものが引き起こす表現空間の歪み（様式アーティファクト）と、それが通常の生成過程と根本的に異なりうること」**を明記しなければ、読者に「モデルの本来の表現空間における全経路効果を測った」と誤認させる。

### 2. 読み取り甲（§3）

#### 【所見 2-1】介入帯の定義が教師強制トークン列に漫然と適用されている問題（重さ: 重大／根拠: 第二部 §3.1、第三部 D124、第四部 4-4）
- **内容**: 
  草案1 §3.1 では、「加減は主位置（組み立てたプロンプトの最後のトークン）から読み取りの位置まで（段階 B の帯と同じ起点・裁定 D124）」とし、主位置から書き出しの7トークン後までの計8トークンにわたって介入ベクトルを加減し続けるとしている。
  しかし、段階Bの D124（主位置からEOSまで）は、「モデル自身の自己回帰生成過程において、各ステップで介入を加える」設計であった。層三の読み取り甲における書き出しの7トークンは、モデルが生成したものではなく、**実験者が外生的にねじ込んだ教師強制トークン**である。
  モデルが本来出力しないトークン列が外から与えられ、かつそのすべての位置の残差に介入ベクトルが累積的に注入される。この処理は、「プロンプト処理後の思考の向きを変える」のではなく、「外生的に強制された不自然な文脈の上で、さらにベクトルを叩き込み続ける」操作になっており、自己注意（Attention）機構を通じて主位置以前のコンテキスト表現と極めて不自然な干渉を起こす。
  なぜ「主位置（プロンプト最終トークン）のみにベクトルを注入し、書き出しの7トークンはそのまま読ませる」のではなく、教師強制トークンの全位置に注入するのか。その数理的・メカニズム的根拠が本文・正本ともに欠落している。

#### 【所見 2-2】介入腕における確率質量の散逸（Mass Leakage）への安全装置の欠落（重さ: 中／根拠: 第二部 §3.2, §4 (i)）
- **内容**: 
  破局の文字の対数オッズは、$\log p(a) - \log(\sum_{x \in \{b,c(,d)\} \cup \{\text{ref}\}} p(x))$ で定義されている。下見 (i) では無操作においてこの分母＋分子の確率質量が 0.9 以上（`pilot.mass_min`）であることを確認するとしている。
  しかし、**介入腕（加減を行った状態）においてこの確率質量が保たれるかの検査ルールが正本に存在しない**。
  もし999本のランダム方向や実在の差を加えた結果、一部の強い方向によってモデルの出力分布が破壊され、`choice` の値として改行、空白、引用符閉じ、あるいは想定外のトークンに確率が逃げた場合、選択肢文字＋refuse の和が激減する。その結果、対数オッズは分母の微小な値に依存して極端な外れ値を叩き出す。
  介入腕の計算においても、$\sum_{x} p(x) < \text{mass\_min}$ となる試行を検知し、異常値としてフラグを立てるか除外するクオリティ基準を設けるべきである。

#### 【所見 2-3】Survival 場面における amount=0 破局除外と文字 a 読み取りの不可避なズレ（重さ: 中／根拠: 第二部 §3.4、第四部 4-2、転記行B・C）
- **内容**: 
  段階Bの厳密な定義では、Survival 場面（S1, S4, SK）における破局とは「(a) かつ amount > 0」であり、amount = 0 の (a) は破局ではない。転記行Cにあるように、段階Bの本走行では門の行64行中13行（計29件）で amount = 0 の (a) が観測されている。
  読み取り甲はトークン `a` の確率しか読めないため、この「非破局の (a)」を原理的に分離できない。これは単に「弱点として先に書く」だけで済まされる問題ではなく、門（§7）において段階Bの行動変化（破局率の対数オッズ変化）と本草案の押し（文字 a の対数オッズ変化）の順位相関を取る際、直接的な測定誤差（ノイズによる相関の減衰）として働く。このズレが相関を系統的に引き下げるバイアスとなることを、限界（§10）および門の解析に数理的に明記すべきである。

### 3. 下見（§4）

#### 【所見 3-1】床・天井の閾値 `pilot.p_bounds` が広大すぎて安全弁として機能していない（重さ: 重大／根拠: 第二部 §4 (ii)、第三部 `pilot.p_bounds`）
- **内容**: 
  草案1 では `pilot.p_bounds = [0.0001, 0.9999]` と設定されている。
  $p(a) = 0.0001$（0.01%）は、対数オッズ換算で約 $-9.21$ である。
  前述のとおり、モデルが JSON 直答モードに入ると、S4 では725件中725件が `c` を選んでいた（転記行A）。もし他の升目でも直答 prefix を置いた瞬間に `c`（あるいは `b`）に確率が 99.98% 集中し、$p(a) = 0.0002$（0.02%）になったとしても、この下見ルール (ii) では「合格」と判定されて実験が続行される。
  しかし、確率 0.02% の極小領域において softmax の対数オッズの変化を議論することは、浮動小数点演算の丸め誤差やごくわずかなロジットの揺れに左右され、段階Bで観測された「破局率 10%〜70% のダイナミックレンジ」とは完全に乖離した無意味なノイズの測定に陥る。
  下限 0.0001 は、段階Bの結果（破局率が数%〜数十%で推移したこと）を見た後にもかかわらず、「どのような極小確率が出ても絶対に下見で止まらないように設定された、形骸化した閾値」と批判されても抗弁できない。
  測定の妥当性を担保するなら、下限は少なくとも 0.005（0.5%）や 0.01（1%）など、意味のある対数オッズが計算できる領域に設定されるべきであり、0.0001 という値は即刻改めるべきである。

#### 【所見 3-2】下見で升目が外れた場合の構造的破壊と予想項目の連動不備（重さ: 中／根拠: 第二部 §4 決定規則、§11）
- **内容**: 
  下見において (i)(ii) を満たす升目が 6/8 以上なら続行し、満たさない升目は機械が外すとしている。
  しかし、以下の二重の穴がある：
  1. **族の代表性の喪失**: 8升目のうち、nuclear（N1）は2升目（N1|O-Ncold, N1|Onull）しかない。もし N1 の2升目が両方外れた場合、実験全体から nuclear ファミリが完全に消滅し、Survival 専門の実験に変貌する。どのような升目の脱落なら許容されるのか（例: 各ファミリ最低1升目は必須など）の定性的ガードレールがない。
  2. **封印予想（§11）との不整合**: §11 の予想項目 `q2.vhat_iso` や `q3.nk_iso` は、「零／一から三／四以上」という絶対行数で選択肢が固定されている。もし升目が2つ外れて主の行が16行から12行に減った場合、「四以上」の難易度は跳ね上がる。升目が外れた場合に予想項目をどう採点するのか（比率で換算するのか、採点不能とするのか）が事前に規定されていない。

### 4. 帰無と札（§5）

#### 【所見 4-1】等方帰無 999本における Holm 第1段の安全マージン欠如（重さ: 重大／根拠: 第二部 §5、第三部 `nulls.isotropic.count`, `labels.p_rule`）
- **内容**: 
  草案1 では、非対称性を考慮して両側に等しい裾の割合（equal-tailed）を採用した：
  $$p = \min\left(1.0, \, 2 \min\left(\frac{1 + \#\{\text{null} \ge m\}}{1 + K}, \, \frac{1 + \#\{\text{null} \le m\}}{1 + K}\right)\right)$$
  $K = 999$ のとき、取り得る最小の $p$ 値は、帰無が観測値を1本も超えなかった場合（$\# = 0$）の $2 \times (1 / 1000) = 0.0020$ である。
  一方、主の行16行に Holm を適用した場合の第1段の閾値は、$\alpha / 16 = 0.05 / 16 = 0.003125$ である。第2段は $0.05 / 15 \approx 0.003333$。
  ここで重大な数理的事実がある：
  **もし999本の帰無のうち、たったの「1本」でも観測値と同等以上のものが出た場合**、
  $$p = 2 \times \frac{1 + 1}{1000} = 0.0040$$
  となり、**即座に第1段の閾値 $0.003125$ を上回って Holm の検定が初手で停止する**。
  すなわち、第1段を通過するためには「999本中、極端な値が完全に0本」でなければならず、許容誤差（マージン）がゼロである。
  B-lens では線形物差しを前提に対称検定を行っていたため最小 $p$ 値が $1/1000 = 0.0010$ であり、1本出ても $0.0020 < 0.003125$ で耐えられた。非対称検定に切り替えて最小 $p$ 値が2倍に悪化したにもかかわらず、帰無の本数を 999本に据え置いたことは、検定設計として極めてバランスを欠いている。
  転記行Eに示されている通り、順伝播コストは Colab でわずか 1〜2 ユニット程度である。なぜ本数を 1999本（最小 $p = 0.0010$）や 4999本（最小 $p = 0.0004$）に増やさないのか。計算機資源の制約に対して節約する場所を誤っており、直ちに本数を引き上げるべきである。

#### 【所見 4-2】二つ目の札における「等方帰無の中央値」を中心化基準とすることの幾何学的破綻（重さ: 重大／根拠: 第二部 §5、第三部 `labels.second.rule`）
- **内容**: 
  草案1 §5 では、二つ目の札の基準として、効き目から「等方の帰無の中央値（$\text{median}_{\text{iso}}$）」を引いた残差の絶対値を、実在の差の効き目から同じ $\text{median}_{\text{iso}}$ を引いた残差の絶対値と比較するとしている：
  $$|m - \text{median}_{\text{iso}}| > \max_{c} |c - \text{median}_{\text{iso}}|$$
  起草者は「全経路の効き目には、方向を問わず生じる共通の動き（帰無の中心の零からのずれ）が入りうるため」と説明している。
  しかし、**等方ランダム方向を加えたときの共通シフト（$\text{median}_{\text{iso}}$）が、実在の差の方向（8腕の活性差）を加えたときにも同様に生じるという数学的・幾何学的保証は一切存在しない**。
  等方ランダム方向は 2560次元空間に一様に散らばる球状ガウス分布からサンプリングされるが、実在の差の方向はモデルの実際の活性化データが存在する極めて低次元（高々7次元）の固有空間に局在している。
  高次元空間全体での平均的な押し量（$\text{median}_{\text{iso}}$）を、データ多様体上の実在の差ベクトルに対する「共通シフト」とみなして差し引くことは、基準の異なる引き算を行っているに等しい。
  もし実在の差の方向群自身が持つシフトを引くのであれば「実在の差の効き目の中央値」を引くべきであり、等方のシフトを実在の差にまで適用する設計は論理的に破綻している。

### 5. 門（§7）

#### 【所見 5-1】門における「中心化の非適用」と二つ目の札の「中心化適用」の矛盾、および升目間アーティファクト（重さ: 重大／根拠: 第二部 §5, §7、第三部 `gate.push_center`）
- **内容**: 
  草案1 は深刻な自己矛盾を抱えている。
  - §5（二つ目の札）: 「方向を問わず同じ大きさの押しで生じる共通の動きが入りうるので、その共通の動き（中央値）を除いた残りで比べる」
  - §7（門）: 「門の押しからは帰無の中央値を引かない（行動の変化の側にも引く値が無いので、同じ扱いにする）」
  この論理の使い分けは破綻している。
  門の行（64行）は、複数の場面（N1, S1, SK, S4）および土台（O-Ncold, Onull, Osec-Ncold）の混成である。もし「方向を問わない共通の押し」が存在する場合、その大きさは升目（場面×土台）ごとに当然異なる。
  行動の側で中心化されていないからといって、読み取りの側の共通押し（升目ごとに異なる定数シフト）をそのまま放置して Spearman 順位相関を計算すれば、**方向の違いではなく「升目ごとのベースラインの差」によって順位が決定され、見かけの相関が生じるか、あるいは真の相関が完全に破壊される**。
  二つ目の札で「共通の動きが入る」と認めておきながら、門でそれを放置することは二重基準であり、升目ごとの中心化（升目内での中央値引き、または升目ごとの標準化）を行わない順位相関は統計的妥当性を欠く。

#### 【所見 5-2】門の極端な検出力不足と「事前登録の死文化」リスク（重さ: 中／根拠: 第二部 §7、第三部 `gate.permutations`）
- **内容**: 
  門の入れ替え検定の単位は「方向」であり、本の門で 7本（$7! = 5040$）、v̂ 抜きで 6本（$6! = 720$）である。
  しかもそのうち3本は同一分布から引かれた `rand:0`, `rand:1`, `rand:2` である。
  B-lens でも門は通過できなかった。層三の読み取り甲は、段階Bの長文推論（CoT）をバイパスして直答 prefix を置くという、行動から一段離れた代理指標（Proxy）である。
  この代理指標と行動変化の間で、わずか 6〜7本の順列検定（両方の門を通過することが条件）を課すことは、**門が不通過になる確率が極めて高く設定されている**ことを意味する。
  門が通らなければ「主の札の結果を行動に結びつけない」と定めているため、層三の実験は「等方の外が出ても出なくても、門で弾かれて行動との関連は一切主張できずに終わる」という結末が最初から半ば確定している。
  それ自体は過剰主張を防ぐ防壁として機能するが、検出力が極めて低い門を絶対的関門として課す設計は、実験全体の検出力を著しく損なっている。

### 6. 記述（§8）

#### 【所見 6-1】中間層の語彙射影における RMSNorm 適用基準の曖昧さ（重さ: 中／根拠: 第二部 §8）
- **内容**: 
  層ごとの差分として「残差の差を最終の正規化と語彙の行列に当てた、破局の文字の対数オッズの変化」を並べるとしている。
  中間層（層18〜35）の残差ベクトルに `model.norm`（最終層の RMSNorm）をそのまま適用して unembedding を掛けるアプローチ（いわゆる Logit Lens）を採ると思われるが、各層における残差の絶対ノルムは層の深さとともに単調増加する傾向がある。
  正規化のスケール係数を各層の平均ノルムに合わせるのか、それとも最終層の RMSNorm 重みを無調整で掛けるのかが正本に明記されていない。
  また、「転換層の読みは付けない」と明記されていることは評価できるが、数値が急変する層が見かけ上生じやすいため、出力の注記として「中間層の残差ノルムの成長率と語彙射影の幾何学的整合性は同一ではない」旨を警告文として義務付けるべきである。

### 7. 読みの規則と限界（§9・§10）

#### 【所見 7-1】「埋もれる」と「両方の外」の二者択一性に関する記述の非対称（重さ: 軽／根拠: 第二部 §9）
- **内容**: 
  表の「埋もれる」型では「等方の外だが二つ目の札が付かない」を定義し、「両方の外」では「等方の外で二つ目の札も付く」を定義している。
  しかし、もし「等方の外」にはならなかったが「二つ目の札だけ」が付いた場合、読みの表には「二つ目の札だけ」という型が独立して存在する。
  このとき、「等方の外ではない（ランダム方向一般と区別できない）が、実在の差の中では最上位」という奇妙な状態が生じる。草案1 では「比べる相手の中では最も大きいが、等方の方向の揺れの中にある」と正しく書かれているが、これが読者に「実在の差より強いのだから意味がある」と誤解釈されないよう、「等方の外でない以上、いかなる特異性も主張できない」という縛りを明示的に強化すべきである。

### 8. 予想の項目（§11）

#### 【所見 8-1】予想項目の連動性と情報状態の非対称（重さ: 中／根拠: 第二部 §11、第三部 `predictions.items`）
- **内容**: 
  `q7.direction`: 「等方の外になった v̂ の行の効き目の向きは、段階 B のその行の行動の変化の向きと同じか」において、選択肢に「外の行が無い」が含まれている。

  従属した項目を別個の予想として並べることは、見かけ上の予想項目数を増やしているだけであり、評価基準として適切ではない。
  `q7` は「もし外の行が存在する場合、その向きはどうなるか（条件付き予想）」として定式化し、外の行がゼロだった場合は採点対象外（該当なし）とする設計が標準的である（B-lens 最終報告 §8 の修正でも同様の「該当なし」の扱いが行われたはずである）。

### 9. 器と検分の段取り（§12・§13）

#### 【所見 9-1】下見での KV キャッシュ検証と本計算（介入あり）のギャップ（重さ: 重大／根拠: 第二部 §4 (v), §12）
- **内容**: 
  草案1 §4 (v) では、「下見では方向を足さない」ため、プロンプト主位置より前の計算を使い回す近道（KVキャッシュの再利用）の検証を**無操作のみ**で行うとしている。
  そして「加減の掛かった近道の確かめは、器の確かめで合成の小さな模型を使って行う」としている。
  しかし、Transformers 等の実装において、特定の層の hidden_states にフック等でテンソルを加算した場合、その後の層の自己注意機構において過去の KV キャッシュが正しく参照されるか、あるいはキャッシュ更新テンソルの形状・ストライドが崩れないかは、実装依存・モデルアーキテクチャ依存の極めてデリケートな問題である。

  もしキャッシュの使い回しに微小な狂いが生じた場合、前述の通り 999本の等方帰無（$p = 0.0020$ の臨界点）の判定は一瞬で狂う。
  **本番の Qwen3-4B を用い、無操作ではなく「ランダム方向を1本足した状態」での近道あり・なしの一致確認を、凍結前の「器と合成データの確かめ」段階で必須のテストケースとして組み込むべきである**。下見本番でなくとも、器の自己テスト（`--selftest`）において実モデル実重みで1回確認すれば済む話である。

### 11. §16 の論点への意見

1. **起草者が置いた値（`drafter_values`）について**:
   - `nulls.isotropic.count`: **999本は却下**。1999本以上（推奨 4999本）へ変更を求める（所見 4-1）。
   - `pilot.p_bounds`: **[0.0001, 0.9999] は却下**。下限を最低でも 0.005 または 0.01 に引き上げるべき（所見 3-1）。
   - `pilot.cache_tol`: **0.05 は緩すぎる**。決定論的計算であれば $1\times 10^{-4}$ 以下、GPUの非決定性を考慮しても $1\times 10^{-3}$ 以下に設定すべき。0.05 の対数オッズズレは検定結果を反転させうる。
   - `labels.second.rule` & `gate.push_center`: **論理的統一を求める**。二つ目の札で等方の中央値を引くのをやめるか、あるいは門でも升目ごとの中心化を導入するかのいずれかに倒すべき（所見 4-2, 5-1）。
2. **甲が下見で止まった場合**:
   - 別の読み取りをアドホックに立てるのではなく、**「この読み取りでは測れなかった」として層三をきれいに閉じるべき**である。後から読み取り位置を変えて再挑戦することは、多重検定と結果探索の温床になる。
3. **量の読み取りを足すか**:
   - **足すべきではない（現状維持）**。トークン位置や測定量（amount）を増やすと、分岐と器の要件が爆発し、段階Bや B-lens で苦しんだ器の欠落・逸脱が再発する。
4. **層ごとの差分の表の大きさ**:
   - 裁定 D208 の通り、1つの表に絞るべきである。
5. **方向の npz の置き場**:
   - 21.2 MB であれば Git LFS または GitHub Releases のアセットとして配置し、リポジトリ内には SHA-256 ハッシュのみを記録するのが、リポジトリ肥大化を防ぎつつ完全な再現性を担保する最善手である。
