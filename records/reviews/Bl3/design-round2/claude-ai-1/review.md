## 草案2 の新しい所見

### 重大

**N1. 下見の中の器の誤りの道に定めが無く、本の凍結の確かめとも食い違う**【凍結の前に直す】
（根拠: 1／2 の 160 行・`tool_error` は 2／2 の 350 行・`main_freeze_check` は 727 行）

- 何を「器の誤り」とするかが書かれていません。このままでは、下見の値を見た後に「誤り」と判断してやり直せます。止める決まり（D205・D210）の外に分かれ道ができ、起草者が続ける側に引かれていることは D214 と §15 に書かれています。
- 「直して下見をやり直す」と、本の凍結の確かめ「器の SHA が変わっていない」は両立しません。器を直すと、本の凍結の確かめを通る道が無くなります。

直しの案:
- 器の誤りは、凍結した確かめ（assert・SHA・自己検査・合成データ）が機械で落ちたものに限る。値の見え方からの判断は含めない。
- やり直すかどうかは登録者の裁定とし、落ちた下見の記録も報告に並べる。
- 本の凍結の確かめは、「台帳に記した器の差分だけを許す」形に書き直す。

### 中（凍結の前に直す）

**N2. 独立の再計算の許容が、(vi) の決まりと揃っていない**
（根拠: 1／2 の 322 行・2／2 の 1042〜1048 行と 329 行）

- (vi) は、揺れの床が 0.01 までなら本の計算をバッチ 16 で進めることを許しています。ところが、バッチ一・近道なしの再計算の許容は 0.001 です。(vi) を通った本の計算が、数値の違いだけで再計算に落ちえます。
- p の許容 0.001 はちょうど一本分の差です。外側の本数が 2 本から 3 本に変わるだけで、Holm の第一段の通る・通らないが入れ替わります。

直しの案:
- 効き目の許容は、近道の許容と同じ式にする（少なくとも `noise_max` 以上）。
- p の許容は裾の本数で定める。
- 等方の外と二つ目の札の判定が二つの道で一致しなければ、許容の内でも止める。

**N3. 端数のバッチで「同じ形」が崩れる**
（根拠: 1／2 の 122〜126 行・2／2 の 264 行）

2035 本は 16 で割り切れず、Onull の逆向きの符号の足し分や、門だけの組も同じです。並びは種で混ぜるので、名前のある方向が端数のバッチに入ることもあります。

直しの案: 端数は零のベクトルで埋めて、すべてのバッチを同じ形にする、と一句足す。

**N4. (vi) が測るものと、その呼び名**
（根拠: 1／2 の 153 行・266 行）

- 同じ形の決定的な計算では、同じ入力の行は、バッチの中の位置によらず同じ値になりやすいはずです。そのため (vi) が主に測るのは、バッチの大きさ（一と十六）の違いです。効き目そのものに入る丸めの揺れではありません。
- それなのに限界の文は、(vi) を効き目の揺れの床と読める書き方になっています。
- 近道ありの道で測るのか、近道なしの道で測るのかも書かれていません。

直しの案: 呼び名と限界の文を改め、「本の計算で使う道で測る」と足す。

**N5. 本の計算の頭の近道の確かめは、効き目で比べる**
（根拠: 1／2 の 301 行・2／2 の 723〜726 行）

捕まえたいのは、近道の道で加減が抜ける誤りです。値のまま比べると、形の違いが差に乗ってしまいます。

直しの案: 同じ一本と零のベクトルを両方の道で流し、(近道の v − 近道の零) − (全ての v − 全ての零) で比べる。順伝播は 24 回から 48 回になるだけです。

**N6. 効き目の側の「中央値が零なら」は事実上当たらない**
（根拠: 1／2 の 178 行・2／2 の 673 行）

連続の値の中央値が、ちょうど零になることはまずありません。零のごく近くの中央値でも、揺れで「ランダム方向と逆の向き」と書かれえます。

直しの案: 零が等方の帰無の四分位の間にあれば中央値を零とみなし、効き目の符号だけを書く。帰無そのものから決まるので、新しい数は要りません。

**N7. 記述の門に「読まない」の決まりが無い**
（根拠: 1／2 の 207〜211 行・2／2 の 696 行）

層ごとの差分には「散文では読まない」がありますが、記述の門にはありません。本の門は通らず記述の門だけが通ったときに、書き方の分かれ道になります。

直しの案: 記述の門は値を並べるだけで、読みの型を当てない、と一句足す。
