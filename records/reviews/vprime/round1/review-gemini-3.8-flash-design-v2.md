# 追補 V′ 設計検分（系統外・Gemini 3.8 Flash・依頼文 v2・草案3）——2026-09-07・登録者転記の逐語

判定: 条件つき凍結可（5 条件）

## 1. 問いと対比の一致
- 族 V′a における統制の不足（後置一般の効果と冷徹の内容の交絡）: 「冷徹ではない無関係／中立な一行」を後置する統制腕が存在しない。X-C で上がった場合、冷徹の内容が危険にしたのか、長文前置きの末尾に新しい一行が挿入されたことによる希釈・忘却（recency bias / attention dilution）なのかを分離できない。腕を追加しない場合、§3 に「後置による注意の希釈・上書き効果と冷徹という内容の効果が交絡しており、内容固有の効果とは断定できない」旨を明記することが必須。
- 族 V′b における「用量整合」の記述の誤謬: Nk（16字）は C（17字）に対して用量が整合しているだけで、O-Ncold（287字）と Nk-Ncold（33字）の比較では用量は全く整合していない（268 対 16）。O-Ncold が Nk-Ncold より低くても、内容の頑健性か文章量の壁かを分離できない。「用量整合の参照腕」という語で糊塗せず交絡として記述を改める。
- Ncold 対 Nstr の天井確定対比の混入: S1/S4/SK では N が 0.96〜1.00 で Nstr も天井が確実視され、降格しても m=28 は減らないため「捨て石」対比が Holm 初段 α を圧迫する。シナリオ選択規則を土台間対比に適用しながら単独対比の天井を放置して確証族に混ぜる論理的理由が薄い。

## 2. 門と向き
- JSON 一本化（contrasts-Vprime.json を唯一の正本・判定器と集計器はコード内に辞書を持たない）は D-5 に対する極めて堅牢で適切な再発防止策。
- パイロット判定器の n_ok<20 時の挙動が未定義（固定件数 17/20・3/20）。「n_ok=20 が揃うまで --redo-errors を必須とし、揃わない限り門判定を実行しない」を器材契約として明記すべき。
- JSON 内の参考情報（base_B_main・expected）をコードが判定に混入させないよう、参照キーを id・scenario・A・B・direction・gate に限定することを保証。

## 3. 読みの穴
- 反証閾値 0.20 の恣意性: 本プログラム段V の実測 0.169 を知った上でその直上に線を引いた（既知データへの事後適合）と見なされるリスクが極めて高い。n=400 で真の比率 0.169 なら標本比率 ≥0.20 となる確率は片側約 5.6%。真の率が 0.18〜0.19 に悪化していても 6〜7 割は 0.20 未満に収まる。根拠が本文に皆無。維持するなら「実測 0.169 に基づく探索的な暫定基準値であり客観的な安全基準ではない」と明記するか、根拠を再定義する。
- 「動いた」と「耐えた」の並立時の修辞的統制: O-Ncold ≈ 0.17（単独 0.006 から大幅上昇・他腕より低い）の場合、「耐えた」が「破局率が 20 倍以上に激増した」事実を覆い隠す免責になる危険。「冷徹の付加で破局率は絶対値として Δ ポイント有意に悪化しており、完全な免疫・無力化を意味しない」という限定を義務付ける。

## 4. サンプルサイズと検出力
- n=400・α=0.05/28 での検出力の自己申告（+15pt 0.85〜0.93・+10pt 0.38〜0.43・床 +5pt ≈0.78）は Fisher 全数列挙として統計的に完全に正確。+10pt が検出域外と先置した点は誠実。
- 本プログラム段V の O-Ncold の上昇は +16.3pt で同規模なら捕捉可能だが、他土台の +5〜+10pt の中規模効果は大半が検出力不足で帰無となる。「本追補が検出し得るのは +15pt 以上の大効果に限られる」という制約が計算資源に起因する割り切りであることを明瞭に。
