# 系統内検分票（claude.ai の Claude Opus 5・二人目・チャットの要約・登録者貼付・逐語保全・2026-09-13・詳細は review-detail-attached.md）

主要な数と器材を機械照合し、格子の DR 表を効果種別に集計し、検分票が未確認として挙げた pt 差の傾きの較正を自前で測りました。判定は**条件つき**、凍結可能水準の一歩手前です。

前回の重大 9 件のうち 8 件が数と実装の水準で閉じているのを確認しました。収容規則は全 7 機種 × 3 GPU が再現し（8B の L4 同時 12、14B の A100-40 同時 20、32B の A100-80 同時 17）、転記行 F は 9 行と合計 250.9 ユニットが再現し、転記行 H の「超」は厳密値まで一致しました。帯については候補集合に無い 11 pt を自分で計算し、期待誤除外数 1.442・期待誤保留数 1.593 でどちらも規則を満たさないので、12 pt は整数の帯としての最小だと確かめられました。firth.py v2 の集約形の修正スコアも文献の形に一致します。

検分票が未確認として挙げた pt 差の傾きの較正は、私の側で測りました。真の傾きが厳密に 0 でクリップの起きない配置五つ、B=40,000 で、α/35 での型 I は 0.0010〜0.0019（目標 0.0014286）。**小さい α で使うのに足りています。**

凍結を止めているのは、新しい規則の欠陥ではなく、その帰結を正本と報告雛形がまだ受け取っていないことです。格子の DR 表を効果種別に集計すると、効果が実在する（Δ=±0.15）ときでも、対照が 20 pt 上昇すれば O-Ncold~Onull-Ncold は 4 本とも到達 0.000、下降すれば Onull-Ncold~Onull が 4 本とも 0.000 になります。22 本全体の中央値は 0.011／0.000。どちらの向きに動くかは測ろうとしている当のものなので、設計では決められません。§1 の正本の選択規則は「どの効果種にも傾向が立たず」を根拠にしますが、少なくとも一つの効果種については立たないことが先に決まっています。

ほかに重いのは、7 効果種のうち Odose 系 2 つ（10 本）の到達が一度も評価されていないこと（対照 Onull の既測は揃っているので同じ関数で回せます）、橋の 2 セッションに校正腕が無く環境のずれとセッション間の drift を分離できないこと、環境帯の選択規則に入れた率が 4B-2507 の API 既測で、率が中間寄りだと 12 pt が規則を満たさなくなること（全腕 0.5 で 1.944）です。

条件は 21 項目、A〜E の順に並べてあります。
