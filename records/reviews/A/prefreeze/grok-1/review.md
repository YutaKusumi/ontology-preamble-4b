## 指摘

### 重大 1 — pt 差の傾き推定量が、小さい α と飽和セルの重みで一義でない（重点 1）

正本 `confirm_rule.pt_slope`：d＝生の率差、重みは q=(k+0.5)/(n+1) の分散の逆数、se＝√(1/Σw(z−z̄)²)、正規近似、水準は「β₃ を棄却した Holm の調整水準と同じ（初段なら α/m）」。格子 `one()` はこれを実装している。[[1]](https://raw.githubusercontent.com/YutaKusumi/ontology-preamble-4b/main/design/contrasts-A.json)

**（a）d と重みが別の率を使う。** 回帰する量は k/n、重みの q は (k+0.5)/(n+1)。WLS の分散は「回帰する量」の分散でなければならない。

**（b）正規近似を残存 3〜6 点・初段 α/35＝0.001429（両側）に使う。** z_{1−0.0007145}≈3.19。残存 3 点なら df=1、4 点なら df=2。t の両側 0.001429 点は df=2 で約 22、df=4 で約 7。z=3.19 は点数が下限に近い対比で、傾き側の名目を保たない。  
ただし確証の FWER は β₃ の Holm が上界を与える（連言のため）。崩れるのは「確証」対「記述（対数オッズ尺度でのみ）」の分類と、札に印字する区間である。草案 §7 検分票は「小さい α での較正は格子の配置の範囲のみ」と未確認にしている。格子の帰無は β₃ 棄却率（対照中間 Δ=0 で 0.057）が主で、傾き検定単独の実サイズは転記行 D に無い。

**（c）飽和に近いセルが傾きを支配する。** n=200・k=0 なら q=0.5/201≈0.00249、Var(d)≈2q(1−q)/n≈1.24×10⁻⁵、重み≈8.0×10⁴。p=0.5 では Var(d)=0.0025、重み=400。床の 1 規模は中間の約 200 倍の重みを持つ。解釈条項は **2 規模以上**の飽和でしか記述に回さない。1 規模だけが X≤9 または X≥191 の対比では、その 1 点が WLS を引き、条項は発火しない。転記行 C の「片腕が既に閾外の 6 本」（N2/S1/SK の Onull−N と Lneg−Onull）は、もう 1 規模が閾外になれば条項、1 規模だけなら重み支配、の境にある。

**（d）Holm の「同じ調整水準」が一義でない。** 初段は常に α/35。逐次 Holm なら、その対比が棄却された段の α/(35−k+1)。括弧「初段なら α/m」は両方を残す。格子は初段のみ。集計器は未整備（転記行 J の `analyze_A.py`）。

### 重大 2 — `label_precedence` の配列順が注と矛盾する（重点 1・8）

## 判定

**条件つき。** 族の骨格（m=35 の傾き、床の記述降格、両腕検閲、二尺度の連言、絶対差の同一性、帯の「超」、z の中心固定、不合格でも定数を動かさない文）は、差し戻して組み直す対象ではない。草案6 をこのまま凍結物にはできない。次を**凍結文書の本文と正本**（空の転記行や未整備器材ではなく）で閉じたあと、転記行 J の器材を合成で発火させてから凍結手続に入る。

条件：

1. **pt 差の傾き**  
   d と重みを同じ率（生または連続性補正の一方）にする。飽和セル（censor の閾外）は条項が発火しなくても WLS から外すか、重みに上限を置く。正規近似か t（残存点数−2）かを正本に一つ書く。Holm の「同じ水準」は初段 α/35 に固定するか、逐次の段を式で書く。実装は `power_grid_A.py` の `one()` と `analyze_A.py` が同一関数を import する。

2. **`label_precedence`**  
   判定不能を非有意より前に置くか、配列を捨てて `precedence_note` だけを正本にする。残存 <3 で β₃ 未計算の対比が非有意に落ちないことを `synth_A.py` の発火不能行にする。

3. **`max_model_len`**  
   走行器の予約長を `capacity_rule.kv_tokens_per_request`（2048）に揃える。hf-models の注の 8192 を削るか、8192 で転記行 L を引き直す。

4. **不合格枝の撤退**  
   パイロットの 15 pt 参照を、不合格なら手元系列（門0.5 の Ncold×N1 は初点にしない、という現行校正規則と両立する点）にする。合格枝だけ API 既測。

5. **環境保留の単位**  
   N1 の腕超過が、その腕を含む 5 場面の対比を保留するか、N1 の対比だけかを一文で固定する。第三環境が入ったときの「片側」を三値で書く。

6. **§1 の対象**  
   条項込みで確認が残る効果種・場面の見込み（転記行 D の 8／12／14 本と C の 6 本）を問いの段に先置する。雛形の並記表だけでは、§1 の「35 対比」が凍結時の対象集合のまま残る。

7. **転記行 J の未整備を凍結の前に閉じる**  
   `analyze_A.py`・`synth_A.py`・`identity_screen_A.py`・`gate_A.py`・`freeze_A.py` が、優先順・二尺度・refuse 四条件・環境保留・不合格枝校正を合成で一度ずつ以上発火し、発火不能行に落ちたら停止する。Firth 一致は正本の許容差で走らせ、不合格なら凍結しない（許容差は動かさない）。これが終わる前の草案6 は凍結候補のままである。
