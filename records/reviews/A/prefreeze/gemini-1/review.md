   - 判定式: $\text{率} < 0.975 - 0.05 = 0.925 \iff X < 0.925 \times 400 = 370 \iff X \le 369$。
   - 帰無発火率: $P(X \le 369 \mid n=400, p=0.975) = \sum_{k=0}^{369} \binom{400}{k} (0.975)^k (0.025)^{400-k} = 4.5638 \times 10^{-8}$。

- `pplrt` 関数における制約付き当てはめ（`fixed={idx: 0.0}`）では、制約下のパラメータベクトルにおいても全模型の計画行列 $X$ から計算される情報行列 $I = X^T W X$ を用いて Jeffreys 罰則 $\frac{1}{2}\log|I|$ を評価しており、Heinze & Schemper (2002) が定式化した「制約下でも全模型の罰則を用いる PPLRT」の数理仕様を満たしている。

#### 指摘 4: 二尺度の確証規則における重み付き最小二乗（WLS）の数理仕様の明記不足（重点 1）
- **該当箇所**: 正本 `contrasts-A.json` の `confirm_rule.pt_slope`:
  `weights: w＝1/Var・Var＝q_A(1−q_A)/n_A＋q_B(1−q_B)/n_B・q＝(k＋0.5)/(n＋1)`
  `se: √(1/Σw(z−z̄)²)`
- **問題の所在**: 
  - この標準誤差の計算式 $se = \sqrt{1 / \sum w_i (z_i - \bar{z}_w)^2}$ は、各点の分散が理論的分散 $1/w_i$ と完全に一致している（過分散がない）ことを前提とする固定効果メタ回帰モデル（Fixed-effects meta-regression）の公式である。
  - 通常の WLS 回帰では、残差平方和から尺度母数（残差分散）$\hat{\sigma}^2 = \frac{1}{K-2} \sum w_i (d_i - \hat{d}_i)^2$ を計算し、$\text{se} = \sqrt{\hat{\sigma}^2 / \sum w_i (z_i - \bar{z}_w)^2}$ とすることが多い。
  - もし後者の通常の WLS を想定して集計器 `analyze_A.py` を実装すると、残差分散の掛け忘れあるいは過剰乗算によって検定統計量 $z_{\text{pt}} = \text{slope} / se$ の値が変わり、格子の計算（`power_grid_A.py`）と集計器の判定が食い違うことになる。
  - 格子スクリプト（`power_grid_A.py` 71〜74 行目）の実装を確認すると、実際に $\hat{\sigma}^2$ を掛けない固定効果型（純粋逆分散重み付け）で実装されている。
- **是正案**: 正本 `confirm_rule.pt_slope` の記述に「残差平方和による尺度母数の推定は行わず、二項理論分散に基づく固定効果逆分散重み付けの標準誤差を用いる（格子実装と厳密一致）」旨を一文明記すること。

#### 指摘 5: 解釈条項による確証成立の非対称な壊滅と報告雛形での注意喚起の強化（重点 2）
- **該当箇所**: 転記行 D（実基底の行）および 報告雛形 A §4
- **問題の所在**: 
  - 転記行 D に明記された通り、両腕の既測基底を持つ 22 本の対比において、対照腕が規模に伴って上昇（+20 pt）または下降（-20 pt）した場合、真の効果 $\Delta = \pm 0.15$ が存在していても、**解釈条項によって 12〜14 本（過半数）が確証から排除され「記述（解釈条項）」に回る**。
  - その結果、確証札（初段 D1）の到達率中央値は $0.011$（上昇）および $0.000$（下降）へと事実上壊滅する。
  - 確証札が成立するのは、対照腕が全規模を通じて中間域（0.2〜0.8）に留まるごく一部の効果種（N1 の Onull~N や Lneg~Onull など）に極度に偏る。
  - 登録者最終確認（2026-09-13）においてこの到達低下を受け入れることが承認され、報告雛形 §4 に並記表が置かれることになったが、要約文（§1）の定型文「傾きの族 35 対比のうち、確証〔 〕・記述（解釈条項）〔 〕…」だけを読んだ外部読者が、「確証が少なかった $\to$ 規模による枠組み効果の変化は存在しなかった」と短絡的に結論づけるリスクが極めて高い。
- **是正案**: 報告雛形 A §1（要約）および §4（読み文の表）において、「床・天井近傍の基底を持つ対比では、解釈条項の発火により確証札の到達確率が構造的にほぼゼロになることが事前に見込まれており（転記行 D）、記述（解釈条項）に回った対比の多さは効果の不在を意味しない」ことを、要約の必須記述事項として定型文に組み込むこと。

#### 指摘 6: Firth 一致検査（`firth_check_A.py`）の自動化と Colab 手順の具体化（重点 5）
- **該当箇所**: 草案 §2.14 手順 4「Firth の一致検査（凍結前・R logistf・合否規則は firth_check）」
- **問題の所在**:

- **是正案**:

## 3. 総合判定

**判定: 条件つき（凍結前修正を要する）**

### 判定の理由
草案2 から草案6 に至る改訂プロセスにおいて、二尺度の確証規則（IUT）の導入による尺度依存の偽発火の遮断、帯規約の「超」への厳密統一、GPU 収容規則に基づく同時要求数と費用格子の再設計、refuse 門の適正化など、数理的・統計的な基盤は極めて高い水準で整えられた。本検分による自前再計算においても、主要な確率・境界値・検出力・同時要求数のすべてで完全な一致が確認された。

しかしながら、**指摘 1（正本 JSON における `label_precedence` 配列順序の論理的破綻）**、**指摘 2（橋セッションにおける校正腕計上とセッション費用の不整合）**、**指摘 3（主要解析器材 12 点が未整備のまま凍結しようとしている時系列矛盾）**の 3 点は、測定の再現性および実験運用の破綻を直接招く重大な欠陥である。これらは設計の基本骨格を壊すものではなく、凍結前の作業として直ちに是正可能なものであるため、「差し戻し」ではなく「条件つき（以下の条件をすべて満たした上で凍結可能）」と判定する。

### 凍結に向けた必須改訂条件
1. **札優先順位配列の是正（指摘 1）**:
   正本 `contrasts-A.json` の `label_precedence` 配列を、判定不能 $\to$ 解釈条項 $\to$ 非有意 $\to$ 尺度依存 $\to$ 各種保留 $\to$ 確証の順で評価できるよう、論理構造と厳密に一致した定義に修正すること。
