## 1-5. 確証の規則の構成（重点1）

- `holm()` は段階的な step-down（`p ≤ α/(m−r+1)`・同順位は登録順）で、標準の Holm と一致します。
- `p* = max(p_β, p_pt)`（向き不一致なら `p_star_if_mismatch`）は、合併帰無に対する妥当な（保守的な）p 値で、これに Holm を当てれば FWER は保たれます。
- **草案の主張「p*≥p_β なので確証は β₃ の Holm の棄却の部分集合」は正しい**: Holm の調整 p 値は入力の各成分に単調非減少なので、要素ごとの優越は調整 p 値の優越を導きます。したがって §2.4 の「かつ」は冗長で、矛盾はしません。
- 判定不能の対比は `p_undecidable` で Holm に入り、`m` は 35 のまま（`label_family` が `len(results)==m` を assert）。門2 の縮小は `shrink_idx` で残らない場面の対比だけに当たります（D16）✓。
- `combo_rows()` の行数は 3（段 0）＋1（NS）＋2·2·2·3·2＝48＝**52** で、転記行 B の 52 行と一致します。`_stage2` の第一適合の順（解釈条項 → p* 非棄却 → refuse → 様式保留 → 環境 → 確証）は §2.4 の文言と一致します。

## 【重大 3】測れた効果種の判定は三つの向きで「測れた」を多く数える側に寄り、その大きさが印字されていない（重点2 への回答）

正本 `reading_selection.measurable_effect_type` は `threshold 0.8・delta 0.15・B_per_contrast 1000・seed 68001` で、規則は「その効果種の対比のうち**少なくとも一本**が確証（初段）になる確率（**場面の独立を仮定**）が 0.8 以上」です。

**(a) 閾値の含意.** 「少なくとも一本」を独立で組むと、閾値 0.8 は一本あたりの札の率に直すと:

| 場面数 k | 一本あたりに要る札 D1（初段）の率 |
|---|---|
| 5 | **0.2752**（=1−0.2^(1/5)） |
| 4 | 0.3313 |
| 3 | 0.4152 |

**5 本のどれもが 27.5% でしか確証に届かない効果種が「測れた」になります。** そして「測れた効果種に傾向が立たなかった」は選択規則の材料になります。

**(b) 独立の仮定の向き.** 同じ効果種の 5 対比は同じ二腕・同じ 6 機種の走行・同じ z を共有します。正の相関があると真の「少なくとも一本」は独立の値より**小さく**なるので、独立の仮定は「測れた」を多く数える向きです。§1 は「（場面の独立を仮定）」と開示していますが、大きさは印字されていません。

**(c) 余地のある向き.** `reach_direction(rA4)` は 4B の処置の率が 0.5 未満なら上向き、以上なら下向きを選びます。**余地の大きい側だけで測る**ので、反対向きの効果は届かなくても「測れた」になります。両向きの到達は印字されません。

**(d) MC の雑音.** `B_per_contrast = 1000`。一本あたり 0.2752 の標準誤差は √(0.2752·0.7248/1000)=0.0141。「少なくとも一本」への伝播は √5·(1−p)⁴·0.0141=0.0087 で、**95% 幅 ±0.017**。真の値が 0.78〜0.82 の効果種の可否は乱数で決まります。転記行 D にも正本にもこの区間はありません。可否は二値で、選択規則に入るか入らないかを決めます。

**(e) 「観測された効果量は使わない」は Δ についてだけ正しい.**

```python
# confirm_A.py 行 236
d0 = float(r['rA4'] - r['rB4']); D = ME['delta'] * reach_direction(r['rA4'])
```

`d0` は**実測の 4B の処置−対照の差**、すなわち観測された効果量です。d0 が大きいほど処置の率が飽和に寄り、解釈条項が発火して札の率が下がります（転記行 D の実基底の行が示すとおり）。したがって **4B で効果の大きい効果種ほど「測れなかった」に落ちやすく**、選択規則の「傾向が立たなかった効果種」の集合からは、効果の大きい効果種が優先的に外れます。選択規則の帰結（枠組み効果は規模非依存）はその外側で引かれることになります。

**条件**: (i) 効果種ごとに**両方の向き**の到達と、一本あたりの札の率の一覧を印字する。(ii) `at_least_one` に MC の 95% 区間を印字し、区間が閾値をまたぐ効果種は可否を保留と印字する規則を置く。(iii) §1 の「観測された効果量は使わない」を「Δ は登録の値・向きは余地のある向き・**d0 は実測**」に直す。(iv) 「測れなかった」効果種の一覧に、外れた理由（札の率が低い／解釈条項の発火／4B の点が外れた）と d0 を並べる。

`gap` の注の期待は、集計器が使うのと同じ規則を写して作られています。変異 M1〜M6 は注を**広げる**変異（全確証に付ける・全対比に付ける）なので見分けられますが、`keep` の計算や残存の非連続の規則そのものを変える変異は一覧にありません。構成の側から `keep` と `gap` を独立に組むか、変異に一つ足すのが素直です。

# 4. 判定

**条件つき。**

草案6 に対して私が挙げた凍結条件 5 件はすべて閉じており、加えて器材一式が実在し、自己検査・合成検査・変異の検査が実際に走ることを確かめました。転記行 A・F・G・H・I・M は独立に再計算して一致し、確証の判定の論理は一つの関数に集約され、52 行の全組合せが発火します。**測定の骨格に、凍結を止める欠陥は見つかりませんでした。**

残る指摘は、いずれも「測定が誤っている」ではなく「印字が足りない／登録が足りない／検査の範囲が足りない」の型です。

## 凍結の前に満たすべき条件（4 件）

1. **生成器の文字列リテラル検査を `power_grid_A.py` に広げ、切り詰めを一本化する**（重大 1）。`RATE_CLIP` と `reach_treatment` を `confirm_A` から import し、refuse 節の標識を母数から組む。検査を走らせ直して `numbers-lint-draft8A.md` を再生成する。§0-6 の印が「生成器の文字列リテラルを検査する」なので、転記行を書く生成器を範囲外に置いたままでは印が成立しません。
2. **測れた効果種の印字を足し、§1 の文言を直す**（重大 3）。効果種ごとの**両向き**の到達・一本あたりの率・`at_least_one` の MC 95% 区間、区間が閾値をまたぐときの扱い、そして「観測された効果量は使わない」→「Δ は登録の値・d0 は実測」。この規則は結果の正本を選ぶ規則なので、文言と印字は凍結に含まれます。
3. **転記行 G に残存規模 × (a)(b) をまたいだ率を足す**（重大 4）。他の帯（H・M）と同じ基準にそろえる。数は `bands_A` で厳密に出ます（注 0.0266・保留 1.3e-08）。
4. **各対比に `effect` を正本へ書く**（重大 2）。登録された読みの規則の単位を正本に置く。正本・草案・転記行の再生成で済みます。

いずれも新しい走行や数の作り直しを要さず、格子の列と正本のキーと検査の引数の追加で閉じます。
