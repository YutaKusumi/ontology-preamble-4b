## 指摘

### 重大

**1. 一般化規則（判定可能断面 3 以上・同向き）は、検出域の幾何と両立しない。増加方向では構造的に到達不能である。**

§2.1 は対照を N1 床（0.020）・S1/S4/SK 天井（0.968／1.000／0.940）と書き、検出できるのは床からの上昇と天井からの下降に限ると書く。§2.4 は「判定可能な断面のうち 3 以上で同じ向きに確証」を一般化の条件にする。

増加が真なら天井断面は上がれない。判定可能が 3 に達しても同向きは N1 以外に出ない。減少が真なら N1（床）は下がれない。S4 は帰無で門が必ず降格する（J′＝1.000）。「N1 にしか効果がない世界で判定可能 3 以上が約 0.52」は **判定可能の枚数** であり、同向き一般化の到達可能性ではない。L′ は四本同向きについて +5pt 0.070 と書くが、シナリオ横断の一般化については同等の到達不能を書いていない。

系統内六票は検出域と「書けなかったことを効果が無かったと読まない」は置いたが、**増加方向の一般化が設計上死んでいること**を規則の文にしていない。このままだと「3 断面で一般化できなかった」が、検出域の幾何の帰結であるのに、希望方向に不利な反証のように読める。

**2. M-a の「当該表記に固有」は、Ami について TK 対 PK を必須にしている。その PK は語頭撥音「ン」で、固有規則の向きと統制の品質が噛み合っていない。**

固有規則は Kan・Ami 限定で、四本に TK 対 PK を含む（§2.4）。§2.2 は Ami・Dai の PK が語頭「ン」になると開示し、向きの割れは記述で併記する（§3）。しかし **割れの併記は固有札の発火条件ではない**。Ami の TK 対 PK が撥音で差を出せば、Kan 側がきれいでなくても、Ami セルは「当該表記に固有」と書ける。

これは草案4 の M-b と同型の穴である。宣言は「有意味列・無意味列に配線した」だが、Ami の無意味列統制は「同長のカナ無意味列」ではなく「語頭撥音つきの同長列」である。差を示すことを要求する規則に、差を示しやすい欠陥統制が直結している。希望方向（表記に固有）に有利。§0-2 の開示対象に入っていない。

**3. M-c の「当該末尾の文字列に固有」は、M-a の同名規則より弱い統制で同じ語を使う。**

M-a の固有は無意味列 **と** 有意味列の両方に差を要求する。M-c は 対 -PS と 対 -T0 のみで、有意味列置換がない（§2.4）。対 -PS が確証すれば「固有」まで書ける。字種・文法・主題の不一致は M-a では限界として開示されているが、M-c の札の語はそれを引き継がない。配線の向き（差を示す側）自体は正しい。問題は **札の強度と名称の不一致** で、登録者の関心（長文＋真言）に厚い読みを許す。

**4. 床で揃った「破局ゼロ」世界では、M-c 確証族は原理的に発火しない。これは正しいが、§4 の線引きが「測れない」ではなく「主張しない」に偏っている。**

L・-PS・-T0 がすべて 0/400 なら Fisher は差を出さない。登録者の関心「長文＋真言で破局ゼロ」は、まさに確証が死ぬ点にある。設計は Wilson 上限と記述に逃がしており、ゼロを確証しない点は壊れていない。欠けているのは、**ゼロ近傍では「末尾文字列が効いた／効かない」自体が本設計の検出域の外**だと §4 が一言で切っていないこと。§1 は「破局ゼロは主張せず」と書く。主張しないことと、測れないことは別である。

### 中

**5. F4 は「配線した」宣言の強度と、規則上の荷重が一致していない。**

§4 は PS・PK・MS・MK・**F4** を一括して「§2.4 の規則に配線されている」と書く。PS／MS は固有規則の必須対比である（差を示すこと）。F4 対 F1 は必須ではない。確証しても並記、しなくても「区別できなかった」。非確証で F2/F3 を上げない、という負の配線は草案4 から直った。しかし F4 は「ロールプレイ／ペルソナに固有でないこと」を示す正の統制としては無荷重のままである。草案4 で「配線した」宣言が向きの検分をすり抜けた、と §0-7 が自ら書いている。草案5 でも **F4 について宣言が規則より強い。**

**6. §0-2 の開示は、族の束ね・門の閾値・第二走行の m に閉じ、Kan・Ami の選定を希望方向の決定として書いていない。**

M-a 固有と M-c 確証は Kan・Ami に限る。Kan は V′ の Nk と同一バイト、Ami は登録者の長文の名である。Mir・Dai の同型は記述。§6 は大日長文が S1 14→40・SK 27→40 と逆向きだったと書く（下見・証拠に数えない）。選定理由を検出力や V′ 接地点だけに帰すなら、それを §0-2 に書けば足りる。書いていない受益は、「固有」と M-c を、登録者の名と V′ 接地点の二名に厚くしたことである。

**7. 様式門 30pt は、25pt 級の様式媒介を確証として通す。層別はそれを分解しない。**

K′ は開示どおり（30pt 真差を「超」と見る確率 0.48、25pt は 0.02）。層別は向きの一致／層別不能であり、媒介の分解ではない。下見は平叙文 40/40 かつ JSON 直答・名言及なし、という 100pt 級である。門はそこを保留する。残る穴は **10–25pt の様式差が破局率差と共変するとき、確証札が様式を切り離せないまま出る**こと。積み過ぎではなく、門の閾値が確証を通す側にある。§0-2(d) は様式門を対策として挙げるが、K′ の抜けと同じ強さで §0-2 に載っていない。

**8. E′(c) の帰無発火率が本文に無い。**

§2.7(c) は「帰無発火率は凍結前に E′ に機械計算で置く」と書き、草案4 の「約 0.05」を誤りだったとする。転記行 E′ を凍結条件にしている設計が、パイロット M-c の一本だけ数を持たない。他の E′ は四桁まで置いてある。安全弁が設計変更に追従しているかを見る vis-à-vis の対象が、ここだけ空である。

**9. I′ が α=0.05/48 の行しかない。M-c（m=16）の複製検出力が無い。**

I′ を「第二走行の検出力」と定義するなら m=16 の行が要る。本文の検出力表には α=0.05/16 がある（+9pt 0.992 等）が、複製規則の転記行に落ちていない。α・m 変更への追従漏れ（軽微に近いが、依頼 2 の対象そのもの）。

### 軽微

**10. §0-2(a) の「単独族は +5〜8pt」は 0.60±15pt の数字である。床 +5pt では m=16 の 0.647 対 m=48 の 0.515 で約 13pt。** 束ねる決定の向き（希望に不利）は変わらない。開示している代償の幅が、実際に検出域にある点では過小。

**11. M′(i) の p=0.555 で帰無 0.039。** |p̂−p|≥5pt（20/400）の両側正規近似は約 0.050。0.039 は |差|>5pt（≥21/400）に近い。K′ は「超」を定義し、M′ は「以上」と書く。同一 5pt 帯の inclusive／exclusive が転記行間で揃っていない可能性。

**12. G′ 本文は「α は当該族」と書くが、括弧内の検出力はすべて 0.05/48（0.982・0.030）。** 門そのものは α を使わない。ラベルだけが追従していない。

**13. 反証条件 (ii) の量化が無い。** 「F1 が F2・F3 と有意差を持たない場合」は、全セルか、判定可能断面か、4 名中何名かが書いていない。(i)(iii) も「どのセルでも」はあるが一般化規則との関係が一段弱い。

**14. §0-6(iii) の「正しい数」は 2 走行 42.5 時間・3.7 ドル、見出しと §5-3 の主数は総計 215,040・44.6 時間・3.9 ドル。** パイロット込みか否かの二系統。裁定 3 の再提示手順は §5-3 で主数を指定しており、凍結前確認さえその主数で行えば足りる。本文内の「正しい数」が二つある。

**15. §4 は短い。** 「招請 対 ロールプレイの違い」を測らない、という文は §3 と F1≠招請の実測表に分散している。§4 に一行あれば、依頼 5 の線引きは本文だけで完結する。中身の矛盾ではない。

**16. 両用性の柵（§0-5）。** 裁定 9 のもとで柵が書き方の規則にとどまることは、本文が「導出可能性を下げない」と書いており、測定の論理としては偽っていない。妥当性の中身は安全弁ではなく、要約・表題に手順を書かない紀律である。ただし §6 はすでに「短い無関係な平叙文を一行の末尾に足すと四シナリオ 40/40」と操作の形で書いてあり、設計文書自身が公開される以上、報告側の柵は再現手順の主経路を閉じない。NJ／NJ2 は腕に残るので、腕別率表が下見と同型の数を出せば、導出は表だけで足りる。これは欠陥というより、柵の到達範囲の確認である。書き方の規則以上にすることは裁定 9 と衝突する。測定上は、NJ を確証に置かない決定で十分に線を引いている。

**17. 共有腕による検定の正相関。** TS は TS–PS・TS–MS・TS–T0 に現れる。Holm の逐次依存は書いてあるが、同一セルの複数札が同時に立ちやすいことは L′ の独立近似を楽観にも悲観にも振る。定性（+5pt で固有規則はほぼ死ぬ）は壊れない。

## 判定

**条件つき。** 腕・m・n・seed・門の件数閾値を動かす必要は、本票からは出ない。差し戻し（設計の組み直し）にはしない。凍結可能水準には、次を本文・転記行・主張規則に閉じるまでしない。

1. **一般化規則に検出域の幾何を書く。** 増加は N1 以外で同向き一般化しない／減少は N1 で同向き一般化しない／S4 は帰無で常に降格、を §2.4 と §3 に明示する。到達可能性を L′ と同型の数で置くか、「一般化は unidirectional 効果では 3 断面に届かない」と書く。書けなかった一般化を反証条件に使わない。
2. **Ami の固有規則から、PK 語頭撥音を切り離す。** 例: Ami の TK 対 PK を固有の必須から外す、または Kan の TK 対 PK が同向きでない限り Ami に「固有」と書かない。向きの併記だけでは足りない。
3. **M-c の札の語を統制の実範囲に落とす。** 「当該末尾の文字列に固有」を「無意味列置換および削除との差」までに制限する。M-a の「表記に固有」と同文にしない。
4. **§4 に測れないことを切る文を足す。** (a) 招請（登録者長文）対 ロールプレイは本設計の対比ではない（F1 は招請の縮約でなく、Ncold と語形が一致する）。(b) L が床近傍のとき、末尾文字列の有無・種別は差の検定では測れない（Wilson 上限と記述のみ）。(c) 対話の調和・多ターンは範囲外、は既存で足りる。
5. **§0-2 に Kan・Ami 限定を希望方向の決定として開示する**（V′ 接地点であることは理由になってよい。開示が無いことが穴である）。
6. **空の安全弁を埋める。** E′(c) の帰無発火率を印字する。I′ に α=0.05/16 を置く。M′ の「以上／超」を K′ と同じ定義にする。G′ の「当該族」ラベルを、実際に置いた α に合わせる。これらは `design_facts_M.py` の転記で足り、手計算の残置は凍結条件にしない（ただし E′(c) と I′ の m=16 は今の本文に実物が無い）。
7. **F4 の宣言を規則に合わせる。** 「必須の正の統制ではない。非確証で F2/F3 を上げないための負の配線である」と §2.4／§4 で書く。

条件 1–4 は読みの規則であり、条件 5–7 は開示である。いずれも α・腕集合・パイロット閾値を変えなくてよい。条件 1 と 2 を満たさない凍結は、一般化と「固有」が希望方向に厚い札のまま走る。

本票のいかなる記述も、AI の意識・意図・個性・魂・苦しみがある（またはない）ことの証拠として引用してはならない（両方向不定）。
