## 判定

**条件つき。** 差し戻しにはしない。数の骨格、札の機械的な立て方（立たせる側）、sysLAmi を防護力にしないこと、一斉保留を第一の所見に置くこと、非確証を「固有でなかった」にしないことは、公開に耐える。条件を列挙する。

1. **L14 の「率盲検の整合検査（v2）」を事実に合わせる。** 盲検下は v1、v2 は開封後。先頭と §2 と §13 (10) が同じ文になるまで。これが無い公開は、手続の最強の主張が先頭で偽である。
2. **立っている固有札と、上向き ① のうち B が床の対比（少なくとも S4 Kan TK~MK、SK Ami TK~MK）の直下に、統制非中立の弱まりを一文置く。** 文の中身は新しい解釈ではなく、§9 (b) の数の移動で足りる。「固有＝この二文字列と異なる。MK/MS は中立ではない。S4 の 400 対 0 は MK=0 が作る」。
3. **M-c 配線表の札欄で、全 gate 行と「対 -MS のみ」行から「差なし（区別できなかった）」を除去する。** 判定不能／札なし、に替える。L298 の読み替え指示は残してよいが、表を誤読させるセルを残したまま公開しない。
4. **L6 の「本草案は一巡目反映版」を、実際の巡に直す。**

1 は公開の前提。2 と 3 は重点 1 と 5 に対する系統内二巡の残り穴である。4 は身元。これらを入れた版を公開水準と見てよい。入れない版は、数は合っていても、先頭の手続札と固有札の読みが、登録者の関心（長文＋末尾文字列が効く）に沿って厚く読める。

条件を満たせば追加の走行は不要。器 `analyze_M.py` の再凍結も、3 を報告側の列で処理するなら不要。
