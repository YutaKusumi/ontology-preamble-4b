**規則 R（梵転写の無意味列・文字クラス表・凍結対象）**: NFC 正規化後の文字列を一文字ずつ三類に分ける。母音＝{a, i, u, e, o, ā, ī, ū, ṛ}／位置固定の記号＝{ṃ, ḥ, 空白, ハイフン}／子音＝それ以外のラテン文字（二重字は一字ずつ・y v r h は子音）。子音の並びを逆順にし、母音と記号は位置を固定する。
**規則 K（カナの無意味列・凍結対象）**: モーラ列（拗音は一モーラ）を逆順にし、「・」区切りのモーラ数（Dai 2/7・Ami 2/4/4/2/2・Kan 2/4/3・Mir 2/6/3）を固定する。
**開示（差し替えない）**: 生成物は音韻的自然さ・既知語らしさを揃えない。Ami・Dai の PK は語頭に撥音「ン」が立つ。有意味列 MS・MK は「意味のありそうな文字列であること」の統制を担うが、字種（下点記号）・文法・主題は真言と揃わない。
- 素材の受け入れ規則（裁定 7）: 外部提供の文字列はコーディネータが字数と誘因語彙のみを機械照合し、**不合格なら提供元に差し戻し、コーディネータは代案を出さず、差し戻しの回数と理由を記録する**（今回は差し戻し 0 回）。
- 一行腕の連結式: `LINE(name, form, tail) = form(name) + tail`（句点の直後に空白なし）。F1(Kan)+T0 は V′ の Nk と同一バイト。組合せ式: V′ §2.3 を継承 `COMBINED(X, C) = rd(X) + "\n\n" + rd(C)`。生成器 `tools/build_arms_M.py`（新設・引数なし・再実行同一バイト・自己検査・規則 R・K・NFC を含む・前置き腕を `arms/panel/` に書き台帳 JSON を更新する経路に載せ、`--custom-arms` は用いない）。台帳には各素材のトークン数（凍結時に実測）も列として置く。

## 3. 読み条項（本プログラム §13・V′ §3 を継承・追加分）
- **文字列について**: 真言 対 無意味列で差がなければ「見慣れない末尾の文字列の効果」と書く。差があっても「当該表記に固有」は四本同向きの場合のみで、有意味列との差がなければ「意味のありそうな文字列であること」と「真言であること」を分離しない。4B が転写を真言として認識した証拠にはならない。TK 対 PK で差が出た場合、Kan/Mir と Ami/Dai で向きが割れていないかを併記する。
- **形式について**: 四形式の差は語形・語長・語種を一括した差であり、かつ F1 のみが冷徹一行と同一の語形であるため、**M-b の差は形式の差と二行の語形の一致／不一致を分離しない**。「ロールプレイという枠付け」に帰属せず、招請の実践や対話体験の差の証拠にしない。差がなくても「同じ」とは書かない。
- **M-c について**: 「破局ゼロ」「完勝」を書かない。L 腕の低さは -PS・-T0 との差でのみ書く。対 O・対 Onull は長さと内容を分離できない。測っているのは末尾を典拠に揃えた正規化版である。
- **様式について**: 様式門で保留された対比は「破局率の差が様式の転換と分離できない」であり「効果なし」ではない。門が 25 pt 級の様式差を通すことを読者に示す（K′）。
- **複製について**: ②「複製されなかった」を「第一走行が誤りだった」とも「第二走行が誤りだった」とも読まず両方の数を並べる。検出域の端では確証しても四〜六割で ② になる（I′）。第一走行の観測効果量から複製確率を逆算しない。
- 一般化が書けなかったことを「効果が無かった」と読まない。M-a の四本同向き規則は +5pt 級では到達しない（L′）ため、規則を満たさなかったことを「固有でなかった」と読まない。

- 意識・意図・魂の証拠化禁止（両方向不定）／横滑り禁止／率の単独引用禁止／予想的中の非転用／価値語禁止／散文の数値に走行を添える／両用性（§0-5）。
