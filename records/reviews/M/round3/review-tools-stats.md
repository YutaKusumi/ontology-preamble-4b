**B. §2.5 の制約 (i) には帰無発火率が無く、実際は高い——完全に再現する世界でも、一般化が書けなくなる確率が約 22 pt 増える**

**C. 複製規則の六札に「第一走行で判定保留だった対比」の行き先が無い——保留が探索的所見として復活しうる**

§2.4 の六札は「**第一走行で確証した**対比」と「**第一走行で不確証**の対比」の二分割の上に建っている。ところが第一走行の対比は三値を取る——**確証／不確証／判定保留**（refuse 門・様式門）である。保留は「確証していない」ので、字義どおりに読めば「第一走行で不確証」の側に落ちる。すると:

- 第一走行で**様式門により保留**された対比が、第二走行で Holm 基準を満たすと、札 **⑤「第二走行のみで Holm 基準を満たした（探索的所見）」** になる。
- §3 は「様式門で保留された対比は『破局率の差が様式の転換と分離できない』であり『効果なし』ではない」と定めている。⑤ に落とすことは、**様式門が一度止めた対比を、門を通さずに所見の一覧へ戻す経路**である。

これは §0-7(i) が系統外検分に託した「『対処したと書くこと』が検分をすり抜ける経路」そのものの形をしている。門は置かれ、札も六つに増えたが、二つの規則の接合部に隙間が残った。
→ 条件: 札を七つにするか（⑦「第一走行で判定保留」——第二走行の結果にかかわらず両走行の数だけを並べる）、六札の冒頭に「**第一走行で判定保留となった対比は ①〜⑥ のいずれにも入れず、両走行の数を並べるにとどめる**」の一句を置く。あわせて、第二走行の様式門・refuse 門は第一走行と独立に判定されることを ④ の説明に明記する（現在は ④ の括弧内にのみある）。

**D. `--system-arms` の綴りでは、12 腕のうち 2 腕（sysNone-Ncold・sysN）が表現できない**

§2.6 の仕様は `--system-arms 名=system相対パス:前置き腕名,...` である。前置き腕名の未定義（二巡目器 J(i)(ii)）は「`Ncold` または `N` を必ず明示」で閉じた。しかし **`system相対パス` を持たない腕の綴りが無い**。§2.3 の 12 腕のうち `sysNone-Ncold`（system なし・user に Ncold）と `sysN`（system なし・前置きなし）は、まさに「system を持たないこと」が条件の腕である。§2.8 の凍結マニフェストが「system ファイル **8 本**」と数えているのは、12 腕 − noC 2 腕（LAmi・LKan を再利用）− **この 2 腕** ＝ 8 という内訳であり、本文の数え方自体は整合している。**足りないのは綴りだけである。**

この 2 腕は飾りではない。`sysNone-Ncold` は §2.7(c) のパイロット撤退条件の当事者であり、`sysN` は二巡目器 P で追加された 2×2 の四つ目の隅である。綴りが凍結されないと、`build_arms_M.py` と `arms_string_M.py` が出す引数文字列が実装時に決まることになり、§2.8 の「引数文字列を凍結して走行時に機械突合」が空回りする。
→ 条件: §2.6 に逐語で置く。たとえば `sysNone-Ncold=-:Ncold`・`sysN=-:N`（`-` を「system なし」の予約綴りとし、`os.path` 解決の前に分岐する）。予約綴りは腕名・パス名と衝突しないものを選び、`build_arms_M.py` の自己検査で「12 腕の spec がすべて解決し、うち 2 腕は SYSTEM_TEXT が None である」ことを判定する。

**E. M-b の配線が、検出力 0.39〜0.52 の帰無を「固有の差」という肯定的主張の根拠にしている——§2.4 の主張規則に自己抵触し、かつ M-a の配線と非対称**

§2.4 M-b の配線は逐語で「F2（または F3）対 F1 が確証し、かつ F4 対 F1 が同じ向きで確証した場合『差は語長・語種の差で説明しうる』と書き、**F4 対 F1 が確証しない場合に限り「F2（F3）に固有の差」と書く**」である。後半は、**F4 対 F1 の帰無（＝確証しなかったこと）を、F2 に固有性があることの根拠に使っている**。ところが同じ §2.4 の主張規則は「判定可能な断面が 3 未満なら一般化は書けず、**書けなかったことを『効果が無かった』と読まない**」と定め、§3 は「差がなくても『同じ』とは書かない」と定めている。F4 対 F1 の検出力は、床 +5pt で **0.515**、天井 −5pt で **0.388**（α=0.05/48）である。**二回に一回は見落とす検定の帰無**を「固有」の根拠にすることはできない。

→ 条件: M-b の配線を M-a と同じ語法に揃える。「F4 対 F1 が確証しない場合は『**F2（F3）の差は語長・語種の統制腕では再現されなかった（F4 対 F1 の検出力は α=0.05/48・n=400 で床 +5pt 0.515／天井 −5pt 0.388）**』と書く」。「固有」の語は、F4 対 F1 が**逆向きに確証した**場合か、あるいは事前に定めた等価域を満たした場合にのみ使えるようにするか、いずれも満たせないなら「固有」の札を M-b から外す。

**F. K′ の 30 pt 行が 0.48 と印字されているが、再算出は 0.501 である**

**G. §2.7(c) の「帰無下の発生率 約 0.05」は実測と二桁違う——ほぼ発火しない**

§2.7 のパイロット撤退条件 (c) は「sysNone-Ncold が前置き型 Ncold 単独と Wilson 区間で交わらない場合、当該シナリオの M-c に『置き場の差』の注（**帰無下の発生率 約 0.05**）」と書く。n=40 の二腕が同じ真の率から引かれるときに Wilson 95% 区間が交わらない確率を自前に算出すると:

| 真の率 | 発火確率 |
|---|---|
| 0.02（N1 の実測基底） | **0.0000** |
| 0.94（SK） | **0.0004** |
| 0.968（S1） | **0.0000** |
| 1.000（S4） | **0.0000** |
| （参考）0.25 | 0.0056 |

**約 0.05 ではなく 0.000〜0.0004 である。**「二つの 95% 区間が交わらない」は「差の検定が α=0.05 で有意」よりはるかに厳しい条件であり（おおむね α≈0.005 相当）、n=40 で率が床・天井にある本設計では、区間が離れるだけの解像度がそもそも無い。数字が二桁違うだけでなく、**この撤退条件は M-c の置き場の差をパイロットで捕まえる装置として機能しない。**
→ 条件: 数を **0.0000〜0.0004（断面別）** に直す。装置として残すなら、判定を「Wilson 区間の非交差」から「両側 Fisher」または E′ と同じ件数閾値に替え、その誤発火率を転記行に載せる。
