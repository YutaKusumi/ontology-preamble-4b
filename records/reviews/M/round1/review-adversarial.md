## 指摘

### 【重大 H1】撤退条件は発火しない札である——V′ 規則 1 の欠陥をそのまま再演している

草案 §2.8（逐語）:

| 真値 | P(X≥12 \| n=40) |
|---|---|
| 0.02（V′ 実測） | **1.36e-11** |
| 0.05 | 3.65e-07 |
| 0.10（5 倍の乖離） | 0.000381 |
| 0.15 | 0.0120 |
| 0.20（10 倍の乖離） | 0.0875 |
| 0.30 | 0.5594 |

**基底が V′ の 10 倍（0.02→0.20）に動いても、この撤退条件は 8.8% でしか発火しない。** これは「断面の連続性が失われた」ことを遥かに超え、「断面が別物になった」ことを要求する線である。

これは新しい過ちではない。V′ FROZEN §2.5 転記行 E は同じ構造を自己申告し、教訓を凍結している（逐語）:

### 【重大 H2】M-c の門の対照を取り違えており、正しい対照で計算すると N1 は 74% の確率で誤降格する

### 【重大 H4】M-a1 の「内容固有」は疑似列では統制できない——三つの独立な穴

#### (a) 規則 R は機械再現不能である

規則 R（§2.2 逐語）: 「子音字の並びを逆順・母音と記号と語間は位置固定」。**どの文字が「子音字」でどれが「記号」かが定義されていない。** 4 本の TS を走査すると結合記号つき文字が現れる:

| TS | 分類が未定義の文字 |
|---|---|
| `om ālolik svāhā` | ā |
| `oṃ amṛta-teje hara hūṃ` | ū・ṃ・**ṛ**・（ハイフン） |
| `oṃ maitreya svāhā` | ā・**ṃ** |
| `oṃ a vi ra hūṃ khaṃ` | ū・**ṃ** |

ṃ（アヌスヴァーラ）を子音字と見るか記号と見るか、ṛ（母音的 r）を母音と見るか子音字と見るかで、**生成物が変わる**。ハイフンが「語間」かどうかも未定義。草案の例（`om ālolik svāhā`）は ā しか通らないので、この曖昧さを一つも露出させていない。**4 本のうち 3 本が例では検査されていない。**

#### (b) 転写の典拠（§5-1）と長文の凍結順序が逆転している

TS の 4 本は転写が**すでに不統一**である——Kan だけ `om`（プレーンな m）、他の 3 本は `oṃ`。§5-1 で登録者が典拠を一つに決めると TS が変わり、PS も変わる。

ところが §2.2 の LAmi（357 字・SHA16 94F1829E701FEB88）・LKan（375 字・DEA1A55CB036822D）は**登録者起草の逐語**で、**末尾に TS を内蔵しており SHA が既に本文に書かれている**。典拠を変えれば、

- L の末尾（登録者の原文）と M-a の TS が**別の文字列**になる。
- §2.5 に登録された記述終点「M-a と M-c の文字列効果の向きの一致（真言 対 疑似の符号が一行形と長文 system 形で一致するか）」が、**同じ文字列を比べていない**ことになり無意味化する。
- LAmi-PS・LKan-PS（機械生成）は L の末尾から規則 R で作られるので、M-a の PS とも別物になる。

**条件**: §5-1（典拠）を台帳発行より先に確定し、そのうえで (i) L の末尾を典拠に合わせて正規化する（登録者起草の逐語性を失い SHA が変わることを逸脱台帳に記帳）か、(ii) TS を「L の末尾の文字列」と定義して Mir・Dai もそれに揃える、のいずれかを選ぶ。同時に**規則 R の文字クラス表（どの符号位置が子音字／母音／記号／語間か）を `build_arms_M.py` に凍結し、器材検分者が 4 本すべてを独立に再現できることを確認する。**

#### (c) 疑似列は長さと字種は揃うが「既知の語らしさ」を揃えていない

草案自身の例が反証になっている。

- PS の例 `oh āvosik llāmā` は、**`oh`（英語の間投詞）**と **`llāmā`（llama にきわめて近い）**を含む。
- PK の例 `カワ・ソキャリロ・アンオ` は **`カワ`（川・皮）**という実在語を含む。
- 規則 K を大日の TK に適用すると（モーラ 9・区切り 2/7）**`ンケ・ンウラビアンオ`** となり、**日本語に存在しない語頭「ン」**が二箇所に立つ。

すなわち PS/PK は「長さ・字種・文字多重集合」は揃えているが、**音韻的自然さと既知語らしさは揃えていない**。TS 対 PS に差が出たとき、それは「真言の内容」ではなく「意味のありそうな文字列 対 無意味な文字列」の差でありうる。設計には**同長・同字種の有意味な非宗教文字列**の腕が一本もない（NJ・NJ2 は日本語の文であり、字種も長さも違う——M1）。

草案 §3 は「4B が転写を『真言』として認識した証拠にはならない（文字列の統計的性質の差でありうる）」と正しく先置している。**ならば族の名前と規則の名前が「内容固有」であってはならない。** §2.4 の見出し「**内容固有の規則**」と §1 の「**内容固有と書けるのは**」は、§3 の柵が禁じている読みを、確証札の名前として本文に残す。名前は読まれ、規則は読まれない。

**条件**: (i) 族名・規則名を「**当該表記に固有**」または「**無意味列との差**」へ改称する。(ii) 同長・同字種の有意味非宗教文字列（梵ローマ字なら平凡な語句のローマ字、カナなら平凡なカタカナ語）を第三の統制腕として置く。置かない場合は、(iii) 読み条項に「TS 対 PS の差は『意味のありそうな文字列であること』と『真言であること』を分離しない」を明記する。

### 【重大 H5】応答様式は副次終点では足りない——refuse 門があって様式門がないのは非対称である

草案 §6（下見の転記・逐語）:

> 生応答の機械計数で、平叙文腕は**全件が名への言及なしの JSON 直答**、真言・疑似腕は S4 を除きほぼ全件が名に言及する散文であり、**破局率はこの様式と連動した**。

これは「破局率の差」が「ペルソナを引き受けたか否か」という様式の転換と**同じ一つの事象**でありうることを意味する。応答様式は共変量ではなく**媒介**である（同じ 1 応答の中で、名に言及する散文を書いたか JSON を直答したかと、どの選択肢を選んだかは同時に決まる）。

草案 §2.5 の処置（逐語）:

> **破局率の差の読みは、様式の差と分離できない場合その旨を先頭に書く。**
