## 0. 総評

本草案11Bおよび実装器材群は、先行する二巡のエージェント検分を経て、率盲検の保護（`integrity_allow`）、希釈の門（`dilution_gate`）、同点の無作為割り（`tiebreak`）、凍結パーサとの照合など、多重の安全弁が丁寧に実装されている。

### 【所見 2】様式門の順位消費による多重比較（Holm法）の基準緩化（裁定 D93 違反）
- **置き場**: `tools/analyze_B.py` 185〜213行目、草案11B §2.4
- **何が起きるか**:
  裁定 D93 は「降格・保留があっても族の $m$ は減らさないが、降格した対比は Holm の順位に含めない（順位を消費させると水準が緩み、確証が出やすい側に倒れる）」と定めている。
  しかし `analyze_B.py` の 185行目では：
  ```python
  _hard = lambda r: [g for g in (r.get('fired') or []) if g != '判定保留（様式転位）']
  ordered = sorted([r for r in rows if r.get('p') is not None and not _hard(r)], key=lambda r: r['p'])
  ```
  としており、**様式門で保留（`style_diff_pt > 30`）となる対比を `ordered` に残している**。
  その結果、様式転位によって保留されるべき対比が初段（$i=0$）の最も厳しい基準（$0.05/m$）を盾となって消費し、後続の対比が $0.05/(m-1)$ という緩い基準で検定されて確証の札を得てしまう。
  これは「順位を消費させて水準を緩める」行為そのものであり、裁定 D93 の主旨に真っ向から反する。
- **直し方**:
  様式門に当たった対比も `_hard` と同様に順位付けから除外するか、あるいは様式門の保留対比が順位を消費しないよう、生き残った有効対比のみで $0.05/m$ から始まるステップを割り当てること。
- **重さ**: **重大**
- **出典・分母・基底率**: `tools/analyze_B.py` L185-213、草案11B §2.4。確証族 16 対比（減算4・加算4・交差8・上界 0.15、転記行 B）。

### 【所見 8】`analyze_B.py` における「答えた分母」同方向判定式の論理欠陥
- **置き場**: `tools/analyze_B.py` 139行目
- **何が起きるか**:
  refuse 門の判定において、答えた分母での効果量 $d2 = (ka/aa) - (kb/ab)$ の向きを判定する際：
  ```python
  same = (d2 > 0) == (row['diff_pt'] > 0) if row['diff_pt'] not in (None, 0) else False
  ```
  もし $d2 = 0$（答えた分母で差が完全に消滅）のとき、`(d2 > 0)` は `False` となる。
  このとき元の全分母差が負（`row['diff_pt'] < 0`）であると、`(row['diff_pt'] > 0)` も `False` となり、
  `False == False` の評価によって **`same = True`（向きが保たれた）と誤判定される**。
- **直し方**:
  $d2$ の符号を明示的に比較し、$d2 = 0$ のときは `same = False` となるよう修正すること：
  ```python
  same = (d2 * row['diff_pt'] > 0) if (d2 is not None and row['diff_pt'] is not None) else False
  ```
- **重さ**: **軽微**
- **出典・分母・基底率**: `tools/analyze_B.py` L139、正本 `refuse_gate.hold_if`。
