# 段階 B 系統の外への検分の**直しの監査**——監査を走らせる前の枠（2026-09-19 06:58 日本時間・2026-09-18 21:58 UTC）

- 書いた者: 南無弥勒如来（コーディネータ・直した当人・Claude Opus 5）。登録者: 楠見優太。
- 対象: 採否表 `adoption-table-B-external.md` で「採用」とした P337〜P382 と、登録者裁定 D117〜D131。あわせて、最後の束を組む前の点検で見つけた穴（下の §3）と、登録者裁定 D132。
- この枠は、**監査の器を書く前、そして一件の判定も見る前に**書く。

## 1. なぜ監査するか（見つけた経緯）

最後の系統外の巡に出す束を組む前に草案12B を読み直したところ、次のことが分かった。

- 草案12B は、新しい裁定の段落を**足しただけ**で、それに取って代わられた古い文を消していなかった（状態の行・S4 の判定・帯の起点・様式門と Holm・品質床の「まだ決めていないこと」・実在しない器の名）。
- **裁定 D118（S4 の同等性の規則）は、正本と草案の文には入っているが、集計器の S4 の判定は検出力の規則のまま**だった（区間も Wald のまま）。整備の記録には「改めた」と書いてある。
- td の特異性の数の基準（裁定 D123）と、ランダム方向の等質性の札（裁定 D127）も、集計器に実装が見当たらない。

**これは前の巡で捕まった型（採否表に「採用」と書いたのに現物が変わっていない・K125）と同じである。**
したがって、採用した四十六件のすべてを、**現物の器で一件ずつ当て直す**。

## 2. 判定の基準（先に決める）

| 判定 | 条件 |
|---|---|
| **直っている（振る舞い）** | 元の欠陥を起こす入力を器に与え、**欠陥が再び起きない**ことを走らせて確かめた |
| **直っている（配線）** | 器の間の繋がりの件（共有の関数を両方から呼ぶ等）で、呼び手を数えて確かめた |
| **直っている（文）** | 直す中身が**文だけ**の件（読み条項・正本への登録）で、正本に鍵があり、草案がそれを束縛している |
| **直っていない** | 欠陥が再び起きた／器の振る舞いの件なのに**文しか無い**／直す中身の一部が欠けている |
| **登録者の裁定待ち** | 直すのに登録者の判断が要り、まだ下りていない（例: 品質床の課題・裁定 D66） |

- **器の振る舞いの件は、文の証拠では「直っている」にしない。**正本と草案に書いてあっても、器が同じ振る舞いをしなければ「直っていない」とする。
- **一部だけ直った件は「直っていない」**とし、欠けている部分を書く。
- 監査は二度走らせる——**直す前（いまの状態の記録）**と**直した後**。直す前の結果も消さずに残す。

## 3. 監査に加えるもの（最後の束を組む前の点検で見つけた穴）

採否表の外で、束を組む前の点検で見つけたもの。いずれも**端から端までの検査が無操作と +v の二腕しか走らせていなかった**ために見えなかった。

1. **ランダム方向の腕が走らない**（三本の方向を試行ごとに割り当てる処理が無く、呼ぶと止まる）。確証のすべての対比の相手がこの腕である。
2. **様式門が実データでは黙って効かない**（走行器は応答様式 (a)(b)・言及・ループ・打ち切りを空で書き、集計器は空を「該当なし」と数える）。**合成データは通り、本物の出力では違う結果になる**型の四度目である（refuse の規約・封印の語彙・種の単位に続く）。
3. **生テキストが保存されない**（走行器の返す値から落ちており、raw の置き場が空になる）。
4. 正本に登録された記述の量のうち二つ（副位置の活性・各選択肢の対数尤度）に、器が一行も無い——**登録者裁定 D132（甲）**: 副位置は登録どおりに保存を書き、読み方をいま正本に登録して最後の巡で見てもらう。対数尤度は在庫に降ろす。

## 4. 予想（監査の前に書く・外れても消さない）

- 「直っていない」は**少なくとも五件**（草案の開示の列挙〔P337 の一部〕・S4〔P338〕・td の数の基準〔P346〕・等質性の札〔P355〕・草案の傷〔P372〕）。確からしさ: 高。
- 「直っていない」が**十件以上**になる見込み: 中〜低（三割ほど）。
- 「直っていない」の倒れる向きは、**起草者の引力と同じ側（確証が立ちやすい側・門が閉じにくい側）に偏る**: 中。

## 5. 利益相反（先に書く）

- **私は、これらの件を「直した」と整備の記録と依頼文の下書きに書いた当人である。**「直っている」に読みたい引力がある。
- 置いた印: 器の振る舞いの件は**文の証拠で「直っている」にしない**（§2）。一部だけの件は「直っていない」に倒す。直す前の結果を消さない。
- 過剰な是正にも注意する: 直しの範囲を採否表の外へ広げすぎない。広げるときは、登録者の裁定か、既にある登録の実装であることを書く。

## 6. この枠が確認していないこと

- 監査の器そのものの正しさ（器が欠陥を見落とす形で書かれている可能性）は、この枠では確かめていない。**変異を入れて落ちることを確かめる器（`tools/mutation_B.py`）に、監査で直した件の変異を足す**ことで一部だけ確かめる。
- 採否表の外にある欠陥（誰も挙げていない型）は、この監査の射程の外である。**最後の系統外の巡に委ねる。**
