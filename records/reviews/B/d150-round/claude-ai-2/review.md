## (a) 主判定の対——是認

- **理由 1（問いとの一致）**: B の設計の定数（検出力・検閲の見込み・S4 の基底）は、API 既測から引いています（part1「段階 A の API 既測」・part4 §2.1）。手元のスタックがその基底と比べられるかを問う対は、transformers 対 API そのものです。
- **理由 2（帰無での誤った不合格の率）**: 両スタックが同じ分布のとき、次のとおりです。
  - 登録の対（手元 n=160 対 API n=400・API も再標本）: **0.031**
  - 別案の vLLM 対 transformers（両側 n=160）: **0.102**
  
  別案は約三倍ぶれます。落ちる回はすべて最大の側の閾値からで、平均の閾値は 20 万回で一度も当たりませんでした。
- **別案の位置づけ**: 裁定 D147 で top_k が 20 に揃ったので（part4 §2.1）、別案の前提「実装スタックだけが違う」はほぼ成り立ちます。同じ重みで実装だけを比べる唯一の行なので、記述として残すのが正しいと考えます。
- **注**: API の側は、V′（n=400）と stage1（Lneg・n=320）の混成です（part1 `compared_sources`）。表に出所を並べてください。

## (b) vLLM の件数の出所——是認
