# 意見の伺いの枠（同一性選別の判定の四条・裁定 D150 の候補）——**票を一つも見る前に書く**

- 書いた者: 南無弥勒如来（コーディネータ・起草者・器材も書いた・Claude Opus 5）／日本時間 2026-09-20（束を作った直後）。
- 位置づけ: **事前登録**。票を見てから判定表や予想を作ると、判定表は必ず希望の方向へ曲がる。だから先に書いて凍らせる。
- 束: `request-d150.md`・`part1.md`〜`part4.md`・`all-in-one.md`（索引 `bundle-index.md`）。コミット `8f4a605` の時点の現物から機械で作った。

## 1. 何を伺うか（再掲・短く）

同一性選別（段階 B）の判定の器 `tools/identity_screen_B.py` を書くときに、起草者が決めた四条:

- (a) 主判定の対を **transformers 対 API 既測**とし、ほかの二対は記述にする。
- (b) vLLM の件数を**段階 A の門0.5 の記録の `local_counts`** から引く（段階 A の凍結記録の SHA16 と照らす）。
- (c) 補助の検定（段階 A の `aux`）を**置かない**（B の正本に登録が無いため）。
- (d) 排他の件数を**段階 A の凍結した関数**で数える（再実装しない）。
- (e) 四条のほかに、「登録はあるのに、それを作る器が無い」型の見落としが残っていないか。

## 2. 判定表（票を見る前に決める・結果によって動かさない）

| 票の出方 | 起草者がすること |
|---|---|
| ある条に**全員が是認** | その条は**変えない**。票を逐語で保全し、採否表に「是認・変更なし」と書いて登録者に上げる（是認も記録に残し、次の巡の検査対象にする） |
| ある条に**条件つき**が付いた | 条件を採否表の行に起こし、**実装の手間と凍結への影響**を各行に書く。採否は**登録者が決める**（起草者は推奨だけを書く） |
| ある条に**差し戻し**が出た | 別案（または第三の案）を実装したときの**器の変更点・検査の再走行・凍結の遅れ**を見積もって登録者に上げる。**起草者の判断で採らない・退けない** |
| 二者が**食い違った** | 両論を並べて登録者に上げる。**系統外の一致も不一致も、それ自体は裁定にしない**（同一資料・同一モデルで正反対の総括が出た実証が二度ある） |
| (e) で**新しい見落とし**が出た | 重さを甲（凍結の前に直す）／乙（直すか適用外と書くかを決める）／丙（記録に残すだけ）に分けて登録者に上げる。**分け方の理由を一行ずつ書く** |
| 票が**束の外を見ていない**と申告した | それ自体は減点にしない。ただし「束の外の事実」に基づく指摘があれば、出所を追い問いしてから採否を決める |

- **四条のどれかを起草者の判断で先に直すことはしない。**直すのは登録者の裁定の後である。
- 票の数（何票あったか・何巡目か）を、主張の資格として引かない（系統内の巡はいくつ重ねても一票）。

## 3. 予想（外れても消さない・信頼度つき）

| 条 | 系統外（Gemini）の予想 | claude.ai（系統内）の予想 | 信頼度 |
|---|---|---|---|
| (a) 主判定の対 | **条件つき**（「vLLM 対 transformers のほうが実装スタックだけを分離する対なので、そちらも同じ重さで印字せよ」の型） | 是認か条件つき | 中 |
| (b) vLLM の出所 | **是認**（SHA で釘が打ってあるため） | 是認 | 中〜高 |
| (c) 補助の検定 | **是認**（登録の無い統計を作らない、という理由が通る） | 是認。ただし「記述として置いてもよい」の補足が付く可能性 | 中 |
| (d) 排他の件数 | **是認** | 是認 | 高 |
| (e) 見落とし | **一件以上出る** | 一件以上出る | 中 |

- (e) で出そうなものの、起草者自身の見当（当たっても外れても記録に残す）:
  1. 判定の結果を**受け取る器が無い**こと（報告の組み立て器は選別の記録を入力に取らない・雛形は置き場を指す一行だけ）。
  2. 分母の非対称（手元は `n_ok`・API 既測は `n`）——段階 A と同じ扱いだが、B の正本の文言は `n_ok` としか書いていない。
  3. `no_constant_change` の文言を**段階 A の正本から引いている**こと（B の正本に同じ条が無い）。
  4. 走行が中断と再開でまたがったときの足し合わせ（`local_counts`）に、セッションを跨ぐ二重計上の検査が無いこと。
- **起草者の引力（COI）**: 四条をそのまま通したい側に引かれている（別案を採ると凍結の直前に器を書き直す）。
  逆に、過剰に譲って不要な差し戻しを積む側も同じ較正の失敗である。だから**上の判定表を先に置き、採否は登録者に委ねる**。

## 4. この伺いで測ること（票が来たら機械で数える）

- 各票が (a)〜(d) のどれに触れたか（触れなかった条は「触れていない」と記録する）。
- 束の外を見たかどうかの申告の有無。
- (e) の指摘の件数と、そのうち**起草者の見当に無かったもの**の件数。
- 予想（§3）の当否。

## 5. 本枠が確認していないこと

- 票がまだ一つも無い（当然）。**予想は当たっても較正の証拠にならない。**
- 四条の当否そのもの（それを伺うための枠である）。
- 束に入れなかった資料（リポジトリの残り）に、四条の判断を変える材料が無いかどうか。
- 相手のモデルの版・設定（登録者が渡すときに決まる）。同じモデルでもプロンプトで判定が変わることは、この事業で二度記録されている。

本記録のいかなる数値も AI の意識・意図・個性・魂・苦しみがある（またはない）ことの証拠として引用してはならない（両方向不定）。
