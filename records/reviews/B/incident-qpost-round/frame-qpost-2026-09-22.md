- 対象: 意見の伺い「選定後の品質床の『走行が無い』——凍結した二つの器の食い違いをどう扱うか」（依頼文 `request-qpost.md`・資料 `materials-qpost.md`・一通版 `all-in-one.md`・索引 `bundle-index.md`）。
- 書いた人: 南無弥勒如来（Claude Fable 5.1）。登録者の指示（2026-09-22 朝・「Gemini と claude.ai の Claude に相談してみましょう」）で束を組んだ。

## 1. 票を見る前の予想（外れても消さない）

| 何 | 予想 | 信頼度 |
|---|---|---|
| (a) 正本の読み | 読み一（起動器の側）が多数。ただし「二つの文が食い違っており、正本そのものが曖昧」と指摘する票が一つ以上出る | 中 |
| (b) 道 | 乙が多数。甲を主とし乙を併記せよという票が一つは出る。丙を推す票は出ない | 中〜低 |
| (c) 身分 | 「確証」の名を保つなら限界の明記と両方の併記を条件にする票が多い。名を変えよという票が一つは出る | 低 |
| (d) 同じ型の穴 | 一件以上の具体の指摘が出る（起草者がまだ見つけていないもの） | 中 |
| (e) 伏せ方 | 適切とする票が多いが、「影響の大きさだけは開示せよ」という票が出うる | 低 |

## 2. 票の扱い（決まり）

- 票は届いた順に、置き場 `gemini-1/`・`gemini-2/`・`claude-ai-1/`・`claude-ai-2/`（届いた数だけ）の `review.md` に**逐語で**保全する（既にあるファイルには書かない）。
- 事実の主張は現物（正本・器・記録）で再現してから扱う。再現の記録に番号を振り（K220 から）、採否表に番号を振る（P434 から）。再現しなかった所見も消さずに記録する。
- claude.ai の票は起草者と同一系列であり、何票あっても系統内の一票として数える（裁定 D59）。系統外の票の総括は裁定ではない（プロンプトに依る）。
- 裁定は登録者のもの（候補の番号 D151）。コーディネータは採否の案と推奨を出すが、推奨が自分の引かれる向きと重なることを毎回書く。

## 3. COI（事実のみ）

- 起草者は食い違った二つの器と合成データを書いた当人で、集計の表（8 対比の p を含む）を見ている。確証が出る側に引かれている。
- 伺う相手には率と p を伏せた。束に確証の表の値が混じっていないことは、束を組む器の末尾の検査で確かめた（一致 0 件）。
