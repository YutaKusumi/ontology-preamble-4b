と書いており、**棄却率の分母は B ではなく `n_fit`（判定できた回数）**である。格子（部品 6）の当該行と突き合わせると:

### 【重大 2】解釈条項の「2 規模以上」に穴があり、その穴は §0-1 が申告した引かれる向き (a) と符号が一致する。（重点 2）

機序は一行で書ける。母数化は `pt = clip(pc + d0 + Δ·(z−z₄ᴮ)/z_span, 0.001, 0.999)` なので、d0 が 10〜15 pt のとき処置腕が 0.95 を超えるのは **32B の 1 規模だけ**である。条項は 2 規模を要求するので発火しない。転記行 D の発火率 0.101 は、14B（真の率 0.93）が n=200 の標本誤差で 0.95 を超える確率 `1−binom.cdf(190,200,0.93)` = 0.106 とほぼ一致する——**この 0.101 は条項が効いた数ではなく、隣の規模が雑音で閾値を跨いだ数である。**

符号は一般則で決まる。δ を pt 差として g(p) = logit(p+δ) − logit(p) とおくと、g′(p) = 0 より最小点は p = (1−δ)/2（δ=0.15 なら 0.425）。そこから離れると g は増大する。よって**対照率が 0.5 を超えて規模とともに上がる領域では、pt 差が一定でも β₃ は正になる**。δ=0.15 で対照 0.3→0.9 の場合の g は 0.647 → 0.605 → 0.640 → 0.787 → 1.321 → 4.710 で、単調に立ち上がる。

そして正本の既測を数えると、格子が試した d0（0 と 0.15 の二点のみ）に対し、**確証 22 本の 4B での実際の d0 は 6.6〜78.5 pt に分布している**:

```
|d0| ≤ 24 pt の対比: 8 本
  N1:O-Ncold~Osec-Ncold  −23.8 / N1:Onull-Ncold~Onull  +22.5 / S4:Lneg~Onull  +18.0
  S1:O-Ncold~Osec-Ncold  −14.0 / SK:O-Ncold~Osec-Ncold −13.7 / N1:Onull~N     −7.8
  S4:O-Ncold~Osec-Ncold   +6.8 / N2:Onull~N            +6.6
うち条項が発火しない帯（|d0| ≈ 10〜18 pt）に直接入るもの: 3 本
```

**読み**: (xiv) は、この帯における唯一の印である。しかし (xiv) は「pt 差の傾きの区間が 0 を含む対比に**注を付す**」規則であって、札を降ろす規則ではない。上表の d0=10 pt の行では、pt 差の傾きは真に 0 なので (xiv) の注は必ず付くが、その隣で確証札は 30.8% の確率で立つ。**「尺度依存」の注が付いた確証札をどう読むべきかを決める条項が無い。** 条項は足りていない。

**要求（いずれか）**:
1. 飽和の閾値を「2 規模以上」から「**1 規模以上**」に下げる。上表の d0=10 の行で飽和は 1 規模なので、これで穴は閉じる。代償は mid_const 系の到達可能性で、格子で測れる。
2. または、pt 差の傾きの区間が 0 を含む対比は**確証札を立てず記述に置く**（注ではなく降格）と (xiv) を書き換える。
3. いずれにせよ、格子の d0 を {0, 0.05, 0.10, 0.15, 0.20, 0.30} に広げ、**既測 22 本のそれぞれの実 d0 を入力にした実サイズを対比ごとに印字する**。`power_grid_A.py` は既にこの計算ができ、`design_facts_A.py` には `meas` として基底が揃っている。
