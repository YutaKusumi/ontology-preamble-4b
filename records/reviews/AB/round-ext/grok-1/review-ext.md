## 指摘（重大 → 軽微）

### 重大 1 — 対照が床／天井でも β₃ 確証が残る（重点 1）

A §2.5:「両腕とも全分母破局率 <0.05、または両腕とも >0.95 のセルを規模単位で検閲。処置側の片側飽和は記号化し検閲しない。」

A §2.4 解釈条項:「処置腕が 2 規模以上で飽和している場合、β₃ の有意は『対照腕の基底の規模傾向による余地の変化』として記述に置く。」

塞いでいるのは (i) 両腕が同時に床または同時に天井の規模と (ii) 処置が 2 規模以上で飽和したときの**主張**だけである。対照だけが床／天井に張り、処置が中間、という対比は検閲されない。解釈条項は処置飽和のときにだけ発火し、対照飽和のときには発火しない。refuse 門（同節）は「β₃ の符号が全分母と一致しない」ときだけ保留で、符号が揃えば余地由来の β₃ は通る。(v) は対照どうしの差を印字する読みで、β₃ の札を止めない。(xii) は残った規模の端欠落で、残った規模の内側で対照が張り付いている場合を対象にしない。

具体例（効果種 × 場面 × 何が落ち／残るか）。率は門0 §S と F 転記の既測で、A の本走行の予測ではない。設計定数の下でどのセルが両腕条件を満たしうるかの例である。

- **O-Ncold−Onull-Ncold × 各場面**  
  処置 O-Ncold（N1 API 52/400＝0.13、L4 3/40、A100 8/40）は <0.05 でも >0.95 でもない。対照 Onull-Ncold（N1 API 366/400＝0.915、L4 39/40＝0.975）は規模によって >0.95 になりうる。両腕条件は「両腕とも >0.95」を要求するのでこの規模は検閲されない。解釈条項の「処置の飽和」も満たさない。残る規模で対照が天井に張り処置だけが動くと、β₃ は対照の余地の変化で立ちうる。

- **Onull−N × S1／SK**  
  F の U-N は S1 400/400・SK 400/400。対照 N が >0.95 のまま、処置 Onull が 0.95 を下回る規模が残れば、両腕条件は発火しない。β₃ は処置の規模差（対照は天井で定数）として立ちうる。N1 では N は API 307/400＝0.767 で中間なので、この経路は場面依存である。

- **Odosehalf−Onull**  
  門0 で Odosehalf は両 GPU 0/40。処置が全規模で床なら解釈条項が発火し記述へ行く。この効果種は条項の適用対象であり、上の二つとは違う。

- **環境段差（検閲を通った対比すべて）**  
  §2.1 は 0.6B・1.7B・4B＝L4、8B・14B・32B＝A100。両腕が中間で 6 規模が残っても、4B と 8B の間の環境切替が β₃ に乗る。§2.4 の環境共変量は「記述に置く」。§3 (xiii) は橋の差が帯を超えたとき「規模則の当てはめは環境ごとに分けて**描く**」であり、Holm 対象の β₃ 札を保留にしない。帯自体は転記行で未定義。

塞ぎ漏れの形: 両腕条件は単腕の対照側検閲より弱い。草案1 の向き別単腕を捨てた結果、重点 1 の経路のうち「対照だけが張る」側が残る。解釈条項は希望方向 (a) に対して、処置が床の対比では主張を記述に落とすが、対照が天井の対比では落とさない。

### 重大 4 — 選定規則の格子 3 軸のうち主指標に乗らない軸がある（重点 5・8）

B §2.3:「候補＝抽出位置 2 × 層（1/4・1/2・3/4）× 係数（ノルム比 0.5／1／2）。主指標＝**主抽出位置・主方向 (6a) の保留 AUC**（…O 対 Osec の投影値の判別…）。選ぶ規則＝品質床に合格した候補のうち保留 AUC が最大。同値なら浅い層・小さい係数を既定。」

保留 AUC は無操作の隠れ状態の投影の判別である。係数 0.5／1／2 は h ← h ± α·v̂ の操作強度で、投影 AUC を変えない。同じ層・同じ抽出位置の 3 係数は主指標で同値になり、既定で最小係数 0.5 が選ばれる。係数軸は品質床の不合格だけで落ちる。

「主指標＝主抽出位置」と書くと、副抽出位置の候補も主指標が同一になり、抽出位置軸が主指標から消える。同値時の既定は層と係数だけで、抽出位置のタイブレークが無い。

主指標を最大 AUC にすることは、§0-1 の希望 (a)「O の方向が立ってほしい」を格子内で最大化する規則である。付帯 (i) の保留分割は抽出汚染を対象にし、希望方向の選定自体を対象にしない。門1（§2.6）は置換帯の内側なら閉じるので、AUC が帯内なら (a) は止まる。帯外の候補があるとき、規則は最大 AUC を採る。

品質床に合格する候補が 0 のときの選定は書いていない。

調整走行は n=40／腕（§2.10-2）。抽出／保留の分割比が無い。門1 と選定は調整走行の AUC で、本走行の前に凍結する（§2.3・§2.10-3〜4）。n=40 の保留側は数十試行で、転記行 C は空欄。門1 の誤判率の入力が草案に無い。

### 重大 6 — B の確証検定と読みの上限が同じ量でない（重点 6）

B §2.4: 減算／加算／交差は「両側 Fisher・全分母」。続けて「確証は『v の効果がランダム方向の効果と異なる』まで（統制の差は同じ族の内側で機械印字）。」

Fisher の対象は O−v 対 O、Onull+v 対 Onull である。ランダム方向対無操作は「印字」である。v 対ランダムの差の検定（交互作用・差の差の区間・多重比較）は無い。札が立つ量は v 対無操作、書いてよい上限は v 対ランダム、で、後者に対応する棄却規則が無い。

ランダム方向の本数は転記行（空欄）。本数 1 なら印字の分散が大きい。本数が多いなら印字側の多重比較が未定義。

O 減算の床先置（同節）は文として足りる。O が床のままなら減算族は両腕条件で落ちる。そのとき m=5（または場面修正後の m）は α を消費して測れない枠になる。測れる枠は加算族（Onull は門0 で中間）に寄る、とは書いていない。

S4 反証（問い 4・(6b) を S4 の Osec-Ncold に加算）は m=20 のどの族にも入っていない。封印された予測に対応する検定が族の外にある。

### 重大 7 — 床持続を確証に残すこと（重点 2）

再算出（n=200・棄却域 k≤4・独立仮定）:

| 真の率 | 単一セル P(X≤4) | 6 規模同時 | Holm 初段（全 6 規模で k≤2） |
|---|---|---|---|
| 0.01 | 0.948 | 0.727 | 0.096 |
| 0.02 | 0.629 | 0.062 | 0.0002 |
| 0.03 | 0.281 | 0.0005 | ~0 |

単一セル 0.948／0.629／0.281、6 規模積 0.727／0.062／0.0005 は採否表冒頭と一致。Holm 初段は器材統計 #3 の 0.096／0.0002／0.0000 と一致（k≤2 は P(X≤k | n=200, p=0.05) ≤ 0.05/15 になる最大 k）。

検定の形（片側正確二項 → 最大 p の IUT → Holm 15）は水準 α を超えない。帰無（「全 6 規模が 5% 未満」を棄却しない）は出る。真の率 0.02 では 6 規模同時でも到達率 0.062、Holm 込みでは 0.0002 で、到達しないことが先に分かる設定である。真の率 ≈0（4B の O／Nk／Osec は門0 で 0/40）なら P(X≤4)=1 で到達する。したがって「到達不能な確証」ではなく、「p≈0 と p≥0.05 を分ける検定で、p=0.02 帯ではほぼ棄却しない」である。

不足は読み側である。族が棄却しないことを「床を離れた」と読まない文は、規模ごとの「有界性の不成立」（k≥5 の記帳）にはあるが、Holm で族全体が残る場合の定型が無い。転記行 E は空欄で、Holm 初段の列を凍結本文に出す規則は §6-E にあるだけである。確証として残すなら、凍結前に三段の数を本文へ出し、「棄却しない ≠ 床を離れた」を族単位で書く必要がある。そうしないと、到達率 0.0002 の枠が α=0.05 を消費するだけになる。

§5-5 の裁定（確証として残す）自体は、上記の数と両立する。数を本文に置かないまま残すことが穴である。

### 重大 8 — (xi)(xii)(xiii) の射程（重点 3）

A §3 (xi):「β₃ は『規模の効果』ではなく『この系列の機種の並びに沿った変化』であり、規模に帰する読みは書かない。」

表題と §1 は「規模でどう変わるか」「規模（log N）に沿って」。モデルは z＝ln(実パラメータ数)−ln(4B 初版)。禁止しているのは文の種類で、推定式は log N 交互作用のまま。§4 は「規模の効果を訓練の効果から分離したと書かない」までで、表題・§1・傾きの族という名称は (xi) の外。

(xii): 残った規模の一覧を印字し、端を欠いた対比に注を付す。書いていないもの: (1) 残存が非連続（例: 0.6B と 32B だけ）のときの直線の意味、(2) 4B が検閲されたあとも z の中心が 4B のままか、(3) 残った規模がすべて A100 側（8B 以上）のとき (xiii) と同時に起きること。錨帯超過で規模を当てはめから外す規則（§2.7）は (xii) の列挙（検閲・測定不能）に入っていない。落ちる理由が複数あるのに、読み条項は二つだけを名指す。

(xiii): 橋の差が帯を超えたら環境ごとに分けて描く。帯は転記行（空）。超えなければ一本の線で、確認は N1・n=200 の橋だけ（§2.1）。5 場面のうち 4 は環境差の推定が無い。32B が「40GB または載らない場合は時間貸し A100 80GB を別環境」（§2.1）のとき環境は三つ。(xiii) は L4／A100 の切替だけ。§4 に環境と規模を分離しない行は無い（一巡目破器身 #6 の §4 追加分が未移植）。

β₃ を「規模の効果」と読ませない文言の弱点は、禁止が報告文にかかり、Holm 対象の推定量と主図の横軸にはかからないことである。

### 重大 9 — 新設条項の内側（重点 8）

**refuse 門（A §2.4）**  
「β₃ の符号が全分母と一致しない対比は判定保留」。符号だけで、答えた分母での有意も、大きさの変化も見ない。答えた分母で点が少なく Firth が分離気味でも、符号が揃えば通る。フィット不能のときの分岐が無い。床持続族（単一率）への適用が無い。Lneg は門0 で refuse が A100 26/40・API 140/320。破局の規模差が refuse 率の規模差と同時でも、符号一致なら札は保留にならない。一巡目破器身 #2 が B に求めた「破局率が動き refuse も同方向に動いた方向は、選択の移動と回答の取り下げを分離しない」は B §3 に無い。(iii) は方向ベクトルと拒否方向の重なりで、率の転位ではない。

**撤退条件（A §2.8）**
