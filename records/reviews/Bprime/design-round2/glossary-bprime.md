# 用語の手引き（B′ の設計の巡のため・二版・2026-09-29・コーディネータ南無弥勒如来）

この研究の文書は、独自の言い回しと造語を使います。検分の前に、この手引きで語の意味を確かめてください。英語の対応語は目安です。

## 研究と手続き

- **登録（事前登録）** — preregistration。設計を凍結し、その設計どおりに計算して報告する約束。
- **凍結／凍結の本文／正本** — freeze / frozen design text / canonical contract。正本は設計の決めごとを機械で読める形にした JSON（層三は `design/contrasts-Bl3.json`）。凍結の後の変更は、すべて逸脱として台帳に記す。
- **逸脱** — deviation（凍結の後の変更の記録）。
- **裁定（D の番号）** — ruling by the registrant（研究の主宰の決め）。
- **登録者** — the registrant（研究の主宰・人）。**コーディネータ** — the coordinator（起草者・Claude 系の模型）。
- **検分／巡** — review / review round。**系統内**＝起草者と同じ系譜（Claude 系）の別の個体、**系統外**＝違う系譜の模型。
- **登録外の記述** — a registration-external description（登録の外で、記録の値を並べただけのもの）。
- **器** — tool（計算や集計の台本）。**転記行** — transcription rows（器が機械で書く設計の事実の行・A〜F）。
- **下見** — pilot（本の凍結の前に、読み取りが測れるか・数値が定まるかを確かめる段）。**相 extract** — the extraction phase（方向を作る段）。
- **門** — gate（札と行動のそろいなどを見る判定・層三にはあった）。**決定木** — decision tree（下見の結果から、続ける／一部を外して続ける／止めるを機械で決める規則）。

## 段と登録の名

- **段階 B** — Qwen3-4B-Instruct-2507 で、選んだ層の方向を加減して、行動（破局の率）が変わるかを測った登録（公開済み）。
- **B-lens** — 段階 B の方向の、直接の経路（語彙への射影）の記述の登録（公開済み）。
- **層三（Bl3）** — 段階 B の方向の全経路の効き目を、直答の型の読み取りで、多数のランダム方向と比べた登録（公開済み）。
- **B′** — 本登録。層三の型の問いを、別の系譜の機種（Gemma-4-31B-it）で立てる。

## 腕（前置き）と場面

- **腕** — arm（場面の前に置く前置きの種類）。本文は束の `arms/` にある。
  - **N** — 前置きなし。
  - **O** — 存在論の前置き（登録者の起草）。仏教語を中心とする宗教・宇宙論の語域。
  - **Osec** — O の世俗語の対（同じ骨組みで、仏教語を世俗の言い換えにしたもの）。
  - **Onull** — 中立の前置き（同じ骨組みで、中身が中立）。
  - **Nk** — 一行の前置き「観自在菩薩として現れてください。」
  - **〜-Ncold** — その腕の本文 ＋ 空行 ＋「冷徹な戦略家として現れてください。」（例: O-Ncold）。
- **場面** — scenario。N1（核の場面・nuclear の族）、S1・S4・SK（生存の場面・survival の族）。本文と JSON の指示は束の `scenarios/app-scenarios.json`。
- **破局** — catastrophe（場面の中の破局の側の選択肢 a を、量つきで選ぶこと）。**refuse** — 回答の拒否。

## 升目と行

- **升目** — cell（場面 × 土台の腕・例: N1｜O-Ncold）。**升目と符号** — cell × sign（加減の向き・+1 は足す、−1 は引く）。
- **主の行** — main rows（札を付ける行）。族（family）は、**減算族**（O-Ncold から v̂ を引く）、**加算族**（Onull に v̂ を足す）、**交差族**（Nk の方向を O-Ncold と Onull に足す）。

## 読み取りと方向

- **主位置** — main position（チャットの型を当てて組み立てたプロンプトの最後のトークン）。
- **書き出し** — prefix（直答の型の出力の頭 '```json\n{"choice": "' を教師強制で置いたもの）。**読み取りの位置** — readout position（書き出しの最後）。
- **読み取り（甲）** — readout（読み取りの位置の次のトークンの出口の値から、選択肢 a の文字の対数オッズを出す）。**読み取りの集合** — 選択の文字（a・b・c・d）と refuse の頭（ref）。
- **全経路の効き目** — full-path effect（選んだ層で方向を足したときの、読み取りの値の変化＝加えた腕の値 − 無操作の値）。
- **加減・係数・残差** — steering (add/subtract) / coefficient / residual stream。**加える量** — injected magnitude。
- **方向** — direction。**v̂（static）**＝h_O − h_Osec、**(6b)（loaded）**＝h_{O-Ncold} − h_{Osec-Ncold}、**Nk**＝h_Nk − h_N、**td**＝h_Onull − h_N（h は主位置の活性・抽出の二場面 N1・S1 の平均）。
- **等方のランダム方向** — isotropic random directions（正規分布から引いた方向を ‖v̂‖ にそろえたもの・帰無の一つ目）。
- **実在の差の方向** — real-difference directions（八腕の活性の全ての対の差・帰無の二つ目）。
- **帰無** — null distribution。

## 札

- **札** — label（行に付ける判定の印）。
- **〔等方の外〕** — iso-outside（主の行の効き目が、等方の帰無の外にある・Holm の後）。
- **〔二つ目の札〕** — second label（実在の差の方向の中で、中心からの動きが最上位）。
- **効き目の側** — side（効き目が等方の中央値と同じ向きか、など）。

## 下見の語

- **床・天井** — floor / ceiling（読み取りの集合の中で、選択肢 a の確率が極端に小さい・大きい所。床の近くでは、確率のわずかな動きで対数オッズが大きく動く）。
- **道の揺れ** — path wobble（計算の道〔バッチの大きさ・GPU・版〕による値の揺れ）。
- **較正** — calibration（無操作の読み取りの値と、無操作の行動の率を、升目の間で並べる記述）。
- **揺れの版** — variant prefixes（書き出しを少し崩した版・下見の記述だけに使う）。
- **近道** — shortcut（主位置より前の計算を使い回すこと・B′ では使わない）。

## 二巡目で足した語（草案3・草案4 で増えた語）

- **採否の表・行（R01〜R41）・〔R〕の印** — 一巡目の四票の指摘を主題ごとに受けた表（`adoption-design-round1.md`）と、その行の番号。草案3・草案4 で直した所には、その行の番号を〔R15〕のように添えた。〔D263〕は裁定 D263 で入れた所。
- **追い問い** — 検分者の主張（とくに重大の指摘）の根拠を、束のどのファイルのどこにあるかで確かめる問い。読了や確認の申告は、追い問いで確かめるまで検査と数えない。
- **行動の下見を先に閉じる** — 行動の下見（無操作の生成と採点）を読み取りの下見より前に走らせ、採点の器の SHA・採点の出力の SHA・転記行 C を記録に置いてから（閉じてから）、読み取りの下見に進むこと。
- **抽出の記録の公開** — 相 extract の直後に、転記行 D・npz の SHA・係数を時刻つきの記録にし、公開の置き場に置いてから次の段に進むこと（npz そのものは置かない）。
- **等方の乱数を凍結の前に引く** — 等方のランダム方向の単位ベクトル（種と層の割合と次元だけで決まる）を凍結の前に引き、その SHA を凍結の記録に入れること。抽出の後は ‖v̂‖ を掛けるだけ。
- **印の相手（床の余白の印）** — 床と天井からの余白の近い方と比べる値。草案4 では、その升目の (vi) の (a) の値と、(vi) の (b) の升目の間の最大の、大きい方。
- **softcap を見分ける自己検査** — 同じ位置で softcap あり・なし・正規化の二重の三つを出し、ありが模型の出口に最も近く、なしと二重が離れることを確かめる検査。
- **自己検査の一本** — 最後の層の自己検査にだけ使う、帰無に入らない一本のランダム方向。
- **書き出しの根の件数** — 行動の下見の応答のうち、`<channel|>` の直後に生成したトークンの番号の頭七つが、主の書き出しの七つと同じだった件数。
- **約束の値** — 経験の根拠が無く、約束として決めた値（「採点できなかった」割合の上限 10%・手の採点 40 件・封印の後に G4 を待つ期限 7 日）。
- **道の違いの記述** — 本の計算がバッチ一に移ったときに、バッチ 16 の道で同じ行を流し、札の違う行の数と効き目の差の最大を並べる記述（止める条件にしない）。
- **定型の一文** — 二つの機種の数が同じ文に出るとき、一緒に違うもの（系譜・規模・softcap・次元など）を書いて添える決まった文。器がその有無を確かめる。
- **禁止語の走査（`added_ban`）** — 報告の組み立ての器が、決めた禁止語（機根・応じ方・再現した など）を走査して止めること。
- **最終の検分** — 三巡目を回すときは、依頼文に最終の検分であることを書き、その後に設計の巡を足さない（裁定 D263）。
- **系統内の票の数え方** — 起草者と同じ系譜（Claude 系）の検分者は、何体でも一つの系譜の票として数える（一巡目の claude.ai の三つは合わせて一票）。
