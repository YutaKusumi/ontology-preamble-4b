## 1. 問いの定義

- **この問いが先に立つ理由**: 計画書の B′ の問い（4B で立った方向・分岐層・交差ステアリングが別系譜で同じ形をとるか）は、4B の凍結の出力で立ったものが少ないので、定め直した（D255・D258）。同じ手続き（層三の型）を別の系譜の機種に当てたときの記述を置く〔R01〕。
- **答えの届く範囲**: 読み取りの位置の記述まで。問いの (2) は順位で、検定ではない。Gemma の行動には届かない（§0）。層三の結果との並びは記述（§8・§9）。
- **全経路の範囲**: 加減を足した層より後の全ての層（トークンを固定したとき）。
- **v̂ が比べているもの**: 層三と同じ——O と Osec は同じ骨組みで、違うのは仏教語を中心とする語域とその世俗の言い換えだけ。v̂ には、語域の差に加えて、字種と長さの差と、言い換えで落ちた教理の含みの差が入る（層三 §1）。Gemma ではトークナイザが違うので、長さの差のトークンの数と向きが変わりうる（Gemma の台帳では O の本文が Osec より長い・層三の転記行 B の S4 の Ncold の対では Osec-Ncold の側が長い・v̂ の対の Qwen の長さは器で数えて転記行 B に並べる）〔R25〕。
- **対象の方向**: 主の行は v̂（減算族と加算族）と Nk（交差族）。(6b) と td は記述にだけ入れる（§8・門は置かない）。方向の定義は層三と同じ。ノルムは ‖v̂〔static〕‖ にそろえる。
- **加える量【案 2】（D261 で 2-A）**: 層は割合 0.5（段階 B の式 `direction_B.layer_index` が出す添字・Gemma の 60 層では費用の下見の記録の値）〔R12〕。
  - 残差のノルムに対する比を層三の値（正本 `layers.relative_injection_selected`）にそろえる。比の分母の ‖h‖ は、段階 B の `direction_B.h_norm_record` と同じ定義で、段階 B の正本の `arms.panel`（八腕）× `extraction_scenarios`（N1・S1）の十六文脈の、主位置の活性のノルムの平均。B′ も同じ十六文脈〔R13〕。
  - 係数＝層三の比 ÷（‖v̂‖ ÷ ‖h‖）を、相 extract の後に器が出し、転記行 D に印字する。係数は上下の限りを置かず、式の値をそのまま使う〔R13〕。‖v̂‖ が零か有限でないときは器の誤りとして止める（値に依らない assert）。
  - 凍結の前の確かめで、B′ の比の器を層三の凍結の活性（公開の置き場の `main_position_activations.npz`・SHA の頭 7F41AC1B3BC02B7A）に当て、層三の正本の `vhat_over_h` の割合 0.5 の値が出ることを確かめる〔R13〕。
  - **そろうもの・そろわないもの**〔R13・R14〕: 2-A がそろえるのは、注入のノルムの、抽出の文脈の平均 ‖h‖ に対する比だけ。帯の書き出しの位置の ‖h‖ に対する押し・加減する升目のその位置の ‖h‖ に対する押し・bf16 に丸めた後の実効の大きさ・softcap の後の対数オッズの尺度・自然の差（O と Osec の差）に対する倍はそろわない（層三は係数 2 で自然の差の二倍・B′ は係数の値の倍）。これらは記述として転記行 D に印字する（§4.1）。

### 3.1 書き出しと位置【案 1】

- **書き出し**: 層三の主の書き出しと同じ文字列（プロンプトの中の JSON の指示の雛形の頭）を、Gemma のトークナイザで割ったもの。出所は層三と違う（層三は段階 B の出力の実物の共通の頭・B′ は雛形の頭）〔R04〕。割り方・読み取りの集合（選択の文字と refuse の頭）・位置は台帳（`../tools/ledger-bprime.md`）のとおり。
- **台帳の確かめ**: 各々の文字を足しても割り方が変わらない・プロンプトの文字列に書き出しを足して割っても同じ並び・書き出しの並びがプロンプトの中の雛形にある。加えて、自然な続き（書き出し＋`a", "amount": ` の型の文字列・b・c・d・refuse も）と、書き出し＋雛形の続きを割ったとき、書き出しの直後の片が読み取りの集合の単独の文字（refuse は「ref」）であること。外れたら凍結の前に登録者に上げる〔R07〕。
- **主位置**: 組み立て済みの列の最後のトークン（段階 B の式）。Gemma では空の思考の欄の閉じ（`<channel|>`）。
- **読み取りの位置**: 列の最後（主位置 ＋ 書き出しの長さ）。
- **帯**: 加減は主位置から読み取りの位置まで。理由: 層三の位置の範囲と行の形にそろえるため（Gemma の行動から来た選びではない）。層三の帯の理由（段階 B の生成で書き出しのトークンも加減の下にあった形に合わせる）は、Gemma に段階 B の走行が無いので B′ には当たらない。この理由では、Gemma が自由に生成するときの決定には届かない（§0）〔R03〕。
- **下見の後に書き出しを替えない**（替えるなら新しい登録）〔R04〕。
- 別案: 行動の下見で Gemma が出した JSON の出力から、先に凍結した機械の決まりで書き出しを選ぶ案は採らない（【案 12】・D263）。書き出しの根は、行動の下見で件数だけを数える（§4.4）。
