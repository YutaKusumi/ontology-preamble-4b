**文として束にあること**: 0.6899 と「バッチの大きさ 1」は (a)(b) にそのままあります。

## 2. 19 番は「必ずそうなる」か「なりうる」か

**「なりうる」という主張です。** 検分の「縮みます」は言い過ぎで、次の仮定を明示すべきでした。

1. **一次（線形）の近似**。効き目を ⟨Δ, g⟩ で近似しています。Δ は足したベクトル、g は帯の八つの位置の勾配を足し合わせたものです。この近似の下では、ノルム R の一様な向きの等方の方向の効き目の標準偏差は R‖g‖/√d になります。d への依り方が正確なのは、この一次の項の中だけです。
2. **‖g‖ は機種で違う**。したがって「等方の広がりそのものが Gemma で縮む」とは言えません。言えるのは「ノルムをそろえた方向の効き目と、等方の広がりとの比」がおよそ cosθ·√d になることだけです（θ は方向と g の角）。
3. **cosθ が両機種で同じ程度**。「Gemma で〔等方の外〕が付きやすい向き」は、この仮定の上でだけ成り立ちます。根拠は持っていません。Gemma の cosθ が Qwen の約 1/1.45 より小さければ、向きは逆になります。1.45 は √(5376/2560) で、5376 は `records/cost-pilot-record-2026-09-29.md`・「機械の記録から」の「隠れの次元 5376」、2560 は `reference/contrasts-Bl3.json`・`inputs.model.hidden_size` の「"hidden_size": 2560」です。
4. **二次以上の項が小さい**。全経路は非線形です。二次の項は、等方の方向でも零でない平均を作ります。層三の正本は非線形を前提に対称でない割合を使っていて（`labels.p_rule_why`）、帰無の中心は零からずれうると書いています。二次以上の項が効き目の主になる大きさの押しなら、1/√d の議論は成り立ちません。
5. **実在の差の方向と v̂ が、次元とともに縮まない部分空間にある**。これも仮定で、どちらの機種でも確かめていません。

**19 番の重さへの影響**: 「重大」の核は、向きではありません。「棒の高さが機種に依るのに、並べる文と柵に入っていない」という比べにくさの方です。この核は仮定 1〜5 に依りません。向き（Gemma の側に寄る）は仮説として扱ってください。26 番の「どちらの穴も同じ向き」も、19 番については「同じ向きになりうる」に弱めるべきです。13 番の向き（印の無い行が数えられる）は仮説ではありません。

## 4. 25 番の案と (vi) の (a) の分岐の両立

まず、(a) の分岐の理由を書いた文は、正本の `pilot.checks.vi.a` にはありません。以下は、関連する文からの私の読みです。

- `reference/contrasts-Bl3.json`・`pilot.checks.vi.measures`: 「方向の混ざったバッチでの揺れは、独立の再計算の二段目で見る」

- `reference/contrasts-Bl3.json`・`independent_recompute.stages.second.note`: 「本の計算がバッチ一のときは、二段目の二つの道は同じ計算になり、二段目は形だけの確かめになる（一段目は変わらない）」

私の読みでは、(a) の分岐は「無操作の値がバッチの大きさで上限より大きく動くなら、札を出す本の道を、揺れの小さいバッチ一にする」ための選びです。二段目は、本の道がバッチ 16 のままのときに、方向の混ざったバッチの揺れが札を変えないかを見る物差しでした。

**両立する所**: 25 番の案は、本の道を替えません。札はバッチ一の道で出したままです。バッチ 16 の道は、(a) が本の道として退けた道を、札を変えない記述として並べるだけです。これは最終版の頭が測っていないと書いた所に当たります（`reference/results-Bl3-FINAL-head.md`・§0・「この結果が退けた説明」の一つ目: 「ただし、計算の道を替えると無操作の値が動いた（下見の (vi) の (a) と (v)）。道を替えたときに効き目と札がどれだけ動くかは測っていない。」）。

**両立しない所（私の案の誤り）**: 案を「二段目の相手」として置くと、正本の止める決まりとぶつかります。`reference/contrasts-Bl3.json`・`independent_recompute.on_mismatch` は「どちらかの段が一致しなければ（二段目は札の一致で見る・裁定 D234）、結果を開く前に止め、逸脱の台帳に記して登録者に上げる（裁定 D219）」です。(a) が上限を超えた場面では、バッチ 16 の道の札が本の札と違うことは、むしろ見込まれます。二段目に入れると、見込まれた違いで止まってしまいます。25 番で「止める条件にはしない」と書きましたが、二段目の中に置く限り、この決まりと矛盾します。

**直した案**:
- 独立の再計算は層三の二段のまま残します。本の計算がバッチ一のときの二段目が形だけの確かめになることは、限界に書きます。
- それとは別の記述の項として「道の違いの記述」を置きます。本の計算がバッチ一に移ったときに、バッチ 16 の道（本の組み方と同じ並びの種）で同じ行を流し、札の違う行の数と効き目の差の最大を、結果を開いた後に並べます。止める条件にはせず、本の札も変えません。読みの文は先に決めます。
- この非対称には筋があります。本の道がバッチ 16 のとき、(a) は揺れが上限の内だと示しているので、札の不一致は見込まれない誤りの兆しで、止めるのが筋です。本の道がバッチ一のとき、(a) は揺れが上限を超えると示しているので、不一致は見込まれた道の感度で、記述が筋です。
- 費用の目安: `records/cost-pilot-record-2026-09-29.md`・「機械の記録から」の表の後の項に「バッチ 16 の順伝播 1560 回 × 1.878 秒 ＝ 0.814 時間」とあります。ただし方向の本数は枠で決まる前の値です。
