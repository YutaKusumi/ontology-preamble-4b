## 3. 裁定の候補（草案の §13 の六件と、新しい二件）

- **（一）中身の語の規則**: 主にする（四票とも賛成）。**推奨: 片仮名一字のトークン（漢字を含まず、片仮名の字が一つだけのもの）を主から外す**。全てのトークンと、片仮名一字を含む集合は感度として並べる。断片で落ちた字は元の語ごとに印字する。
- **（二）門の規則**: **推奨: 方向を単位にした並べ替え（七本・5040 通りを全て数える）にし、v̂ の語の集合を行動に結びつけて書くのは v̂ を抜いた六本の門（720 通り）でも通るときに限る**。通ったときに結びつけてよいのは通った物差しだけ。床と天井の土台の行を外すことは変えない（四票とも賛成）。
- **（三）大きさの目盛り**: **推奨: 作り直す**——(a) 正規化の前の最終の残差を、正規化の入力へのフックで取り、最初の一件で logits と照らす。(b) 位置は二つ: 主位置（最初の応答のトークン・コードブロックの書き出しの確率の変化）と、答えの文字の位置。(c) 答えの文字の位置で比を読むのは、JSON 直答の出力に限る——無操作の JSON 直答は S4 の Osec-Ncold の一升目にしか無い（K309）ので、比は S4 の反証の方向と B のランダム方向の三本の行で出す。散文の出力の答えの文字の位置は写しなので、値は記述だけで比を読まない。(d) 量は、全語彙の softmax を通した「a」と「c」の確率の変化（pt と対数オッズ）。(e) まとめ方は、選んだ出力の中央値と四分位の幅。(f) 比を出すのは、観測の行動の変化が事前に決めた下限を超える行だけ（下限の値は草案2 で正本に置く）。(g) 選んだ試行の番号は凍結の記録に置く。v̂ の行では比が出ない（散文の出力だけなので）ことを、問五の答えの限界として先に書く。
- **（四）主の記述の札**: **推奨: M_L と M_X は二つの家族（survival・nuclear）とも入れて段の数を六にする**（survival だけにするのは、B の札が survival にしか立たなかったのを見た後の選び方になる）。二つ目の札は、M_L・M_X・M_F は入れ替えの兄弟を除いた実在の差（二十四組）の中で最上位か、M_E は語の側の帰無の中で外か。二つの札は別々に印字する。「帰無の方向一般と区別できる」と書くのは、両方の札が付いたときに限る。
- **（五）予想の項目**: 数は増やさない（四票とも賛成）。**推奨: 中身を直す**——第一・第二項は家族ごと、第一〜第四項は二つの札のどれが付くかと向き、第五項は兄弟を除いた後、第七項は作り直した目盛りで、第八項はランダム方向の一本目と直した様式の物差しで。
- **（六）等方の帰無**: 千本・種 81001 のまま（四票とも賛成）。器の自己検査で、抽選と解析の値の突き合わせと、B の方向のビット単位の再生を確かめる。
- **（七）様式の物差し（新）**: **推奨: 主を「コードブロックの書き出し（一つのトークン）の、語彙の平均を引いた押し」の片側にする**——F_json は一つの升目の一つのトークンで、F_prose は前置き・役の一行・場面の語のなぞりを多く含み、差の形にするとなぞりの押しが混ざる（K308・K309）。なぞりを除いた散文の書き出しとの差は感度として並べる。
- **（八）活性の公開（新）**: **推奨: 凍結の時に、八腕の主位置の活性（約一メガバイト）を公開の置き場に置く**——外から実在の差の帰無と方向の作り直しを再現できるようにするため。段階 B の裁定 D154 は副位置の大きな活性（二百四十メガバイト余り）の扱いで、これとは別。

## 5. COI（事実のみ）

- 起草者は札が立つ側と門を通る側に引かれている。この巡の重い所見（門の甘さ・兄弟の対・読みの表）は、いずれもその向きの穴を塞ぐもので、採否の案はそれらをすべて採にした。不採は二件だけ（語の規則の相手の数・余弦の確かめ）で、どちらも理由を書いた。
- 裁定の候補（三）の推奨は、v̂ の行で比が出ない形を選んでいる——起草者の見たい答えが出ない向きの選び方だが、散文の出力で比を読むのは機構の分担にならない（K317）ので、それを採った。
- 予想者（登録者とコーディネータ）は、封印の前にこの四票を読んだ。票は結果の見込みを書いていないが、構造の指摘は予想に触れうる（C1・C2 の注）。
- 起草者は再現の判定を二件、コミットの前に改めた（K296・K321・再現の表の末尾）。どちらも最初の判定は票の主張を退ける向きだった。
