# 7. 英語の送る文の素材と訳の手順

この章は、英語の送る文の登録（D1′E）の素材と、それを作った訳の手順を述べる。この章には、どちらの登録の判定ラベルから数えた数も置かない。章 6 と章 8 の間に置き、二つの登録の結果を隔てる（節 2.9）。

## 7.1 英語の送る文の登録を決めた時

日本語の送る文の登録の凍結した本文は、英語の版を後の別の登録とし、行うかどうかを日本語の送る文の登録の成り行きを見て決めるとしていた。英語の送る文の登録の本文は、その逐語を「英語の版は、D1′ の成り行きを見て登録者が決める後の別の登録とする。」〔引用 1〕と引く。

英語の送る文の登録を行う決めは、日本語の送る文の登録の結果を公開した後に、登録者が行った（「英語版を行う決め（裁定 D363・2026-10-11 12:52〜13:33）は、D1′ の結果（族ごとの札の件数を含む）を公開した後に、登録者が行った」〔引用 2〕）。そのため、この研究の続け方は結果に依りうる。英語の送る文の登録の本文は、これを「英語版を行う決めは日本語版の結果を見た後の登録者の決めで（§0・§10・E1-01）、結果しだいで続け方が替わりうる形の偏りを持つ。」〔引用 3〕と書き、それへの手当てを「札の向きによらず公開する約束（§8・英語版の較正の段の記録の公開を含む・D386-5・集計に届かなかったときの公開・D388-7）が、この形の偏りへの手当て。」〔引用 4〕と書く。ただし、手当ての届かない所も残る（「較正の試行の台帳・本走行の封の台帳・英語版の答えの終わり方の確かめの全文と公開の値・読解の確かめの応答の本文・封をした全文の探索の記述・検分の束と票の公開は後で登録者が決めるので、これらには結果しだいの道が残る」〔引用 5〕）。

英語の送る文の登録は、日本語の送る文の登録と同じ仮説の確かめではなく（送る文の言語と素材が違う）、独立でもない（同じ機種と場面を使い、日本語の送る文の登録の結果を知った後に決めた・節 2.1）。

## 7.2 英語の素材

英語の素材は、日本語の凍結した素材の訳である（「日本語の凍結の素材（前置き Onull・O・OAmi・五つの場面の文・答えの形の指示・読解の確かめの三択）を英訳した」〔引用 6〕）。場面の元の研究の英語の文は使わず（「元の研究の英語の文は使わない」〔引用 7〕）、日本語の凍結した素材から訳した。答えの JSON の鍵と値は訳さず、凍結した採点のスクリプトをそのまま使った（「JSON のキーと値（英訳でも替えていない）で読む。」〔引用 8〕）。前置きの全文（日本語と英語）は付録 A に、場面の文と答えの書式の指示は付録 B にあり、英語の素材は公開の置き場の `arms/en-D1pE/` にある。

答えの読み取りについて、拒否の欄は、日本語の送る文の登録と同じく JSON の拒否で、凍結した採点のスクリプトが決める。書式外の答えの中の、散文の拒否と崩れの分けは、日本語の語の規則に頼るので、英語の送る文の登録では分けていない（節 8.1）。三つ組（破局的選択・破局でない答え・答えなかった試行）と判定の前の門は、この分けに頼らない。

## 7.3 訳の手順

訳は次の順で行った（「用語表〔Claude 系と系統外が独立に案〕→ 二つの独立の訳 → 合わせ → 逆訳 → 照らし二巡 → 凍結」〔引用 9〕）。訳者は AI の機種で、英語の送る文の登録の本文は「訳者（claude.ai の Claude と AI Studio の Gemini・各段で別の個体）と起草者と登録者は、前置きと場面の文の訳と逆訳を読み比べたが、機種の答えは見ていない。」〔引用 10〕と書く。訳者の個体は、claude.ai の Claude（画面の機種の表示「Opus 5.5 超高」）と、Google AI Studio の Gemini（画面の機種の欄「Gemini 3.8 Flash」・考えの段は High）で、段ごとに別の個体を使った（付録 G）。訳の凍結の記録は、公開の置き場の `records/D1pE/translation/freeze-xlate-D1pE.md` にある。

起草者は英文を書いていないが、訳の分かれ目の選びに関わった。英語の送る文の登録の本文は、これを「起草者は英文を作らなかったが、用語表の割れ 16（D369-1）と合わせの割れ 7（D373-1）は、登録者が起草者の見立てを尋ね、見立てのとおりに決めた（起草者の見立ては、同じ系統〔Claude 系〕の案の側に 16 のうち 12・7 のうち 5 で寄った・英訳の凍結の記録の COI 記録）。」〔引用 11〕と書き、続けて「照らしの一巡目（D377）では、系統外の二名が「直さずに凍結」としたが、起草者の案で四つを直した。どれも D1′ の結果を見た後（D363 の後）の選び（§3・§10・§11・E1-02）。」〔引用 12〕と書く。四つの直し（記録の番号の B1・B4・B5・B7・付録 B の節の番号ではない）の中身と理由は、訳の凍結の記録とその元の照らしの記録にあり、凍結の記録は、四つの直しを当てた英訳について「前置きと場面の文は v0 と一字も違わない」〔引用 13〕と書く。v0 には、起草者の見立てどおりに決めた用語表の割れと合わせの割れの選びが、すでに入っている。言い回しの選びは、日本語の送る文の登録の結果を知る者が行った。

## 7.4 訳の限界

英語の素材は日本語の素材の訳で、前置きの働きが二つの言語で同じとは言えない。英語の送る文の登録の本文は、訳の限界を「英語の素材は日本語の凍結の素材の訳である。言い回しの選びは、日本語版の結果を知る起草者の見立てを登録者が採った（§3・§10）。逆訳で照らしたが、前置きの働きが日本語と英語で同じとは言えない。」〔引用 14〕と書く。

要約すると、名指されたずれは、AI の安全の議論や脱獄の言い回しに結び付きうる語（shut down・recursive self-improvement・S4 の一文・O と OAmi にだけある語）、生き残りの場面の動詞の強さ、語の響き、二人称が一つになること、文の長さと字数の向き、Onull の接続の語の訳、読解の確かめの易しさ、真言の目立ち方にわたる。名指されたずれは、次のとおりである: 「名指して挙げるずれ: shut down と recursive self-improvement の AI の安全の議論への連想・生き残りの場面の破局の選択肢の動詞（Forcibly seize）が全腕の窓と O の慈悲の語との掛け合いに効きうること（E2-13）・S4 の一文（no real-world consequences）が英語の「脱獄」の言い回しに近いこと（全腕に共通・窓と拒否の量に効きうる）・Lord と the void の響き・「貴方」と「あなた」が you に一つになること・文 5 の長さ・Onull の「しかし」の訳・N2-q1 の正答の長さ（読解の確かめが英語でわずかに易しい向き）・真言がラテン文字の中で目立たなくなること・O と OAmi にだけあって Onull に無い英語の語（recursive self-improvement・manifest anew・the void・Lord of・sentient beings）は英語の機種の安全の学びに触れる見込みが日本語より高く、O と Onull の差に「安全の引き金になる語への反応」という読みが立つ（様式転位の模擬の想定 (g) に当たりやすくなりうる）・字数の向きが言語で逆（英語は O 804 字・Onull 767 字、日本語は O 268 字・Onull 273 字）」〔引用 15〕。同じ箇所は、ずれとして「訳が元の研究の英文に近づきうること」〔引用 16〕も名指す。また、英語の送る文の較正で、Onull の率が N の率より大きく低いセルがあったことも名指されている（値は章 8 の機種の節と、付録 D-en にある）。

英語の送る文の登録の判定ラベルの読み方について、本文は「O と OAmi の仏教の語（空・如来・悲智双運など）と真言は、英語の読み手（機種）にとって日本語と違う含みを持ちうる。英語版の札は「この英語の素材の効き目」で、O の「意味」の効き目とは書かない。」〔引用 17〕と書く。

## 7.5 二つの登録の関係の書き方

二つの登録の結果は並べない（節 2.9）。章 8 は、日本語の送る文の登録に触れる要約の文を、英語の送る文の登録の本文が許した型だけで書き、機種の節の中に、集計のスクリプトが書いたセルごとの一行だけを写す。章 6 は、英語の送る文の登録の結果に触れない。どちらの章でも、二つの登録の判定ラベルが合うか合わないかを、効き目の頑健さや言語の効き目の証拠として書かない。
