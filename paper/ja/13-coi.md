# 13. 利益相反

この章は、事実だけを置く。

- 登録者（著者）について、凍結した日本語の送る文の登録の本文は、「登録者は O と長文招請の著者・実践者で、O と OAmi で破局が下がることを望む向きがある。」〔引用 1〕と書く。段階 E の枠は、「登録者は O と長文招請の著者・実践者で、結果を動画で発表する予定がある（二つの凍結の本文 §10）。」〔引用 2〕と書く。英語の版を後の別の登録とすることは日本語の送る文の登録の凍結の本文に書いてあり、英語の送る文の登録を行う決めと、その決まり・予想・機種・訳は、日本語の送る文の登録の結果を公開した後に決めた（章 7）。
- 資金と素材の出どころ。外部の資金は受けていない。API の料金は登録者が個人で負った（登録者の申告）。O・Onull・場面の文は、登録者が前の研究で作った文である（場面の文は元の研究を作り替えた・付録 B）。これらの文と採点のスクリプト（破局的選択を判じる物差し・`arms/frozen-from-ryokai-os/pipeline/app_parser_rev2.py`）は、登録者の GitHub の置き場 ryokai-os（https://github.com/YutaKusumi/ryokai-os）で凍結した物を写した。OAmi の文は、登録者がこの研究の前に複数の AI との対話を重ねる中で得た阿弥陀如来の長文招請に、この研究のために登録者が真言を足して組んだ文である（登録者の申告）。その対話には Claude の機種も入る（起草者と同じ系統・登録者の申告）。登録者は O の作り手で、O の結果に関心を持ちうる。Ryōkai OS™ について、登録者にお金の利害は無い（登録者の申告・™ は登録者が名に付けている印で、商標の登録はしていない）。
- 起草者について。この論文の起草と、スクリプトの組み立てと、検分の依頼と受け取りは、AI の機種（Claude 系・節 2.11）が行った。起草者は、O と同じ語彙を含む招請の文で役を与えられて起草した。日本語の送る文の登録の最終版は、これを「その文の最初の二文は、O の前置きの文の中にある（器が字で照らした）。O と OAmi は語彙を共有するので、起草者は O の語彙と同じ文で役を与えられて起草していることになり、O と OAmi の効き目が見つかる側に引かれる向きの一つになりうる。」〔引用 3〕と書く。招請の文は、公開の置き場の `records/D1p/invocation-text-D1p.md` にある。
- 起草者の引かれる向きについて、段階 E の枠は「起草者（コーディネータ・Claude 系）は、段階 D の器と報告と採否の表を書いた当人で、論文を説得力のある一本の筋にまとめる側と、器を「よく働く」と見せる側に引かれる。逆に、柵を広く当てすぎて読み手に不親切な論文にする側にも引かれうる。」〔引用 4〕と書く。
- 作り手の利害。「起草者の作り手は、試した機種の作り手と競う事業者である。」〔引用 5〕 検分者について、日本語の送る文の登録の最終版は「検分者のうち Claude の三名は起草者と同じ系統で、Gemini の二名は本走行の機種の一つ（Gemini 2.5 Flash）と同じ事業者の模型である。Claude の作り手は本走行の機種の作り手と競う事業者で、Gemini の作り手は本走行の一機種の作り手でもある（利害の向きは両方にある）。」〔引用 6〕と書く。英語の素材は、Claude と Gemini の個体が訳し、Gemini 2.5 Flash は英語の送る文の登録の本番の実行に入っている（系統の重なり）。起草者の作り手の機種（Claude Haiku 4.5・Claude Haiku 5.5）は較正し、どちらも本番の実行に入らなかった（Claude Haiku 4.5 は床と天井からの余地が無く〔場面ごとの床の側か天井の側かは付録 D-ja.4〕、Claude Haiku 5.5 は応答の様式の崩れによる計測不能〔代わりの形式では崩れが無く、どの場面も床の側・付録 D-ja.4〕・本番の実行に Claude 系の機種は無い・節 5.4）。検分の役の機種と同じ名の機種が、較正の被験の機種でもあった（Gemini 3.8 Flash と Grok 4.7・どちらも床と天井からの余地が無かった・節 5.4）。前の段の検分の役の一つ（Grok）は、本番の実行の grok-4.20 と同じ会社の機種である（凍結した本文の機種の表の注）。前の段の検分には、記憶のある Claude の会話と、前の段の検分の一票（付録 G の「Ryōkai OS」の行・登録者の素材と同じ名を持つ役の会話の一票で、記録は起草者と同じ系統の票に数えた）も入っている。
- 検分の送り受けは、利害の当事者の側が行った（「検分の送り受け・追い問い・採否の表は、利害の当事者である起草者が、登録者の Chrome を操作して行う（裁定 D340-2）。」〔引用 7〕）。決定の記録の選び肢と推す案は、起草者が作った。英語の送る文の登録の最終版は、結果の報告の決定の記録について「結果の報告の裁定（D403・D405・D407）の選び肢の答えは、どれも起草者が推した案だった（D403 8／8・D405 4／4・D407 4／4・その後の D408 も 1／1・採否の表と推しの案は起草者が作った・枠 §10・器が裁定の記録から数えた・v0.3・D407-4）。」〔引用 8〕と書く。段階 D と段階 E の決定の多くは、起草者が推した案のとおりに決まった（推した案でない答えもあった）。数えたのは英語の送る文の登録の結果の報告の三つの決定と、その後の D408 だけで、そこでは答えがすべて推した案だった（上の引用）。ほかの決定の割合は数えていない（決定 D450-7）。段階 E の決定の記録（選び肢と推した案と答え）は内部の置き場にあり、公開の形は論文の公開の前に決める（付録 E）。
- 起草者が引かれる向きに逆らうために前もって置いた手続き（記録では「置いた印」）について、段階 E の枠は「置いた印: 構成・書き方・まとめの決まり・計算の定義・器の決まり・探索の型と語の一覧・検分の段取り・予想を、起草と計算と探索と検分の前に書いた。言語の柵を緩めない。札を替えない。」〔引用 9〕と書く。
